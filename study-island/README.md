# 觀護學習島（獨立預覽版）

本頁是「觀護人學習平臺」的原創療癒式遊戲化介面。

**最新版 v3 獨立測試網址：** https://probation-study-island-preview-inp7xcucf-ris001214-3112.vercel.app/ （2026-10-30，已驗證 HTTP 200 且回傳新版 HTML；尚未合併至正式站）。靈感是日常經營、動物鄰居、持續積累的輕鬆感；**不使用任天堂／《動物森友會》角色、音效、遊戲畫面、地圖或其他受保護素材**。

## 試玩

在儲存庫根目錄啟動：

```bash
python3 -m http.server 8781
```

以瀏覽器開啟 `http://localhost:8781/study-island/`。此分支目前尚未整合到正式首頁、PWA 離線清單或資料備份中心，也未部署至正式站。**請先於獨立預覽分支完成測試，再決定是否合併。**

## v3 森系改造（原創美術）

- 原創 SVG 歡迎插畫：小屋、海岸、山丘、樹林、花朵與日光場景。純內嵌圖形，不連結或複製任天堂圖像。
- 原創 SVG 動物居民肖像：栗子、阿棕、小白、墨墨。保留既有親密度與對話。
- 島嶼地面由明顯方格改成更接近自然草地與沙岸；仍是可點擊的 6×6 地塊。
- 小島可重新命名（最多 14 字），沿用既有 `probationStudyIsland.v1` 資料並相容舊版 JSON；不會建立第二份紀錄。
- 新增漫遊模式，可暫時隱藏側邊學習工具，放大島嶼進行布置，再返回原本頁面。
- 首頁顯示裝置本機日期與時刻，手機版採響應式配置，保留系統減少動態效果設定。

## 現有功能

- 六乘六島嶼布置：固定房屋、原生草地，以及可擺放／收回的 6 種商店裝飾。
- 4 位原創動物居民：與不同學科關聯的鼓勵對話；完成特定學習任務可增加居民親密度。
- 日夜及春夏秋冬視覺外觀依瀏覽器本機日期時間切換；小島升級後漸進出現新的公共景物（不覆蓋自己已擺放的家具）。
- 每週完成 3 個不同日期的學習可領取一次委託獎勵；另有學習成就徽章。
- 專注計時：5／25 分鐘；時間依目前裝置的實際時鐘計算，分頁切換／重新整理後可接續；取消不給獎勵。
- 每天最多一次自行回報「完成申論」、「訂正／主動回憶」與「學科／法條閱讀」；不是查證過的考試分數或活動紀錄。
- 貝殼、成長值、小島等級、累計學習天數；**沒有連續簽到壓力、排行榜、付費道具或廣告**。
- 小島資料獨立保存在 `localStorage["probationStudyIsland.v1"]`；可自行匯出與匯入 JSON。

## 安全與資料界線

1. 不讀寫 `study-desk/` 的 IndexedDB、`v2.5/`、`lectures/` 或任何其他既有學習紀錄。
2. 新的 JSON 匯出**不包含原本的考古題答案**；原本備份中心也**不包含小島遊戲紀錄**。不同網域、裝置及瀏覽器不會同步。
3. JSON 匯入會經版本、欄位及裝飾 ID 驗證；匯入時會提示目前小島資料將被覆蓋。重要資料應先備份。
4. 未確認真實的學習行為不得宣稱為自動驗證。每日任務的獎勵完全以使用者誠實自我回報為基礎。
5. 如果瀏覽器拒絕儲存，遊戲會提示；資料可能僅存在當下頁面。請匯出備份。
6. 本版不連接 AI、外部 API、不需帳號，也不收集個資。
