# 觀護學習島 v4｜階段 A＋B＋C（可玩核心、經營循環、學習連結）

依《觀護學習島 v4 開發規格書》實作。已完成第九節的 Demo A，以及第七節的**階段 A（可玩核心）**、**階段 B（經營循環）**與**階段 C（學習連結）**。**這是獨立預覽，不是正式上線功能**；未整合到正式首頁、PWA 離線清單或備份中心。

## 目前可以玩

- 20×16 原創小島（小屋、廣場、小路、樹林、沙灘、海），Canvas 繪製、格子碰撞；地表不畫方格線，海岸是柔和曲線。
- 玩家角色：點地面以 A* 自動尋路繞過房屋、樹、岩石、家具與居民；WASD／方向鍵；可開啟的螢幕方向鍵。撞到障礙時顯示紅色 × 與一句提示。
- **4 位居民**（物種沿用 v3）：栗子（狐狸・少年事件處理法）、阿棕（熊・犯罪學）、小白（兔子・心理學）、墨墨（貓頭鷹・諮商／訂正）。各自在家附近散步；今天還沒聊過的頭上有「！」。對話依親密度改變，每天第一次聊天親密度 +1（上限 10），背包可看親密度。對話只有原創鼓勵與遊戲引導，不含法律或學理知識。
- **4 類材料、11 個每日採集點**：海灘貝殼 ×3、樹林木材 ×3、葉子 ×3、果實 ×2，依本機日期每天重新出現。
- **工坊 3 個配方**（遊戲數值）：木椅（木材×2、葉子×1）、花圃（葉子×2、木材×1）、小燈籠（貝殼×3、木材×1）。缺料時按鈕停用並以紅色標出差多少。
- **家具擺放與收回**：選家具後地圖上以白點標出可擺放的格子。不能擺在小路／路口、採集點、居民的家、玩家或居民身上、已有家具處，也**不能把任何地方封死**（擺放前做連通檢查）。靠近家具按 E，或在「建造」裡按「收回」，可放回背包。新手木凳開局就在背包，可以直接擺。
- **每日遊戲委託**（📒 任務）：撿 2 個貝殼（小白，獎勵葉子×1）、和 2 位居民聊天（阿棕，木材×1）、製作 1 件家具（墨墨，貝殼×2）。進度自動核對，每項每天只能領一次。
- **專注計時（階段 C）**：5／25 分鐘。以「開始時間 + 裝置時鐘」計算，重新整理、切換分頁或關掉再開都會接續；時間到才結算，同一次專注只給一次（獎勵帳本 `focus:開始時間`）。取消不給獎勵也不扣任何東西。每日上限：5 分鐘 3 次、25 分鐘 2 次；超過仍可專注，只是不給獎勵。進行中時頂部顯示 ⏱ 倒數。
- **學習任務（階段 C，自行回報）**：完成一題申論、完成一次訂正、完成一次主動回憶。每項每天一次，需要按兩下（「我完成了」→「確定完成」）避免誤觸，並標示「自行回報」。各附往返連結到考古題練習（`v2.5/`）、備考書桌（`study-desk/`）、主動回憶（`active-recall/`）。**小島不讀取這些頁面的任何資料**；之後正式串接（v4.1）才可能顯示「學習平臺已儲存」。
- 獎勵以材料、少量貝殼與居民親密度為主（專注→阿棕、申論→栗子、訂正→墨墨、主動回憶→小白）；AI 分數或模擬評語一律不計獎勵。
- 存檔：IndexedDB `probation-study-island-v4`。保存位置（角色停下後）、背包、擺放的家具、當日採集與委託紀錄、居民親密度、進行中的專注。

## 試玩

```bash
python3 -m http.server 8790   # 在儲存庫根目錄
```

開啟 `http://localhost:8790/study-island/v4/`。

| 操作 | 手機 | 電腦 |
| --- | --- | --- |
| 移動 | 點地面；或按右下 ✥ 開方向鍵 | WASD／方向鍵、點地面 |
| 互動 | 點居民／貝殼，或底部「互動」 | E（Enter／空白鍵亦可） |
| 背包／任務／建造 | 底部三個按鈕 | B（或 I）／T／C |
| 擺放家具 | 「建造」→「擺放」→ 點白點 | 同左；Esc 取消 |
| 關閉 | ✕ 按鈕 | Esc |

## 資料保全設計

- 撿拾、製作、擺放、收回、領委託：每個動作都在**同一個 IndexedDB readwrite 交易**內「讀最新存檔 → 檢查 → 修改 → 寫回」（`src/state.js` 的 `applyAction`）。交易 commit 後才顯示成功；失敗時提示並顯示橫幅，不假裝已保存。
- 多分頁：IndexedDB 會將 readwrite 交易排隊，所以兩個分頁同時撿同一個採集點、同時送出多次製作，都不會多拿；另以 BroadcastChannel 通知其他分頁更新畫面。
- 委託獎勵以 `rewardLedger["quest:日期:ID"]` 去重；材料、家具與帳本在同一筆交易內更新。
- 存檔中的家具位置若不合理（未知 ID、不可走、重疊、重複 uid），讀取時**收回背包**，不靜默丟棄。
- 無法使用 IndexedDB（例如某些無痕模式）：遊戲照常可玩，但頂部顯示警告，拾取提示會加上「（未保存）」，不假裝已永久保存。
- **不讀寫** `localStorage["probationStudyIsland.v1"]`（v3 小島）、`study-desk/`、`v2.5/`、`lectures/` 或任何考古題資料。唯一的 localStorage 是「方向鍵是否顯示」這個介面偏好。
- 不同網域（Vercel 預覽與 GitHub Pages）存檔不互通。

## 程式結構

```text
study-island/v4/
  index.html  style.css
  src/world/map.js          地圖、地表、碰撞
  src/player/pathfinding.js 4 方向 A*
  src/npc/dialogue.js       居民資料、原創對話、散步
  src/world/placement.js    家具擺放規則與連通檢查
  src/collectibles.js       每日採集點
  src/inventory.js          材料與家具
  src/crafting.js           工坊配方
  src/quests.js             每日遊戲委託
  src/learning.js           專注計時與學習任務（自行回報）
  src/state.js              存檔格式、正規化、所有會改存檔的動作（純函式）
  src/persistence.js        IndexedDB 交易與記憶體後備
  src/render.js             Canvas 繪製（原創向量圖形）
  src/ui.js                 HUD、對話框、抽屜
  src/main.js               輸入、移動、遊戲迴圈接線
  tests/logic.test.mjs      Node 單元測試（已加入 npm test）
  tests/e2e.mjs             Playwright 瀏覽器驗收
```

繪製迴圈只在移動或動畫時以 requestAnimationFrame 執行；閒置時降到約 8 FPS（貝殼閃光），開啟「減少動態效果」時完全停止並停止居民散步。切回分頁時重設計時，角色不會瞬移。
