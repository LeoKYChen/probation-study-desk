# 國考英文＋作文練習站 v0.4（116年觀護人）

這是 `probation-study-desk` 的獨立共同科目模組，入口為 `common-subjects/index.html`。維持原 v2.5／v2.5.4 專業科目題庫及每日訓練不變。

## 功能

### 國文作文
- 舊有12個原創模擬題原樣保留；第一、二、三批合計120個**歷屆題意改編**練習題（短文60、長文60），連同舊有12題，共132題。
- 新題收錄來源為112—114年司法特考三等國文及112—115學年度學測國寫。第二批另外參照109—111學年度國寫，並納入115年司法特考「留白」作文的改編。**115年司法特考原卷PDF未直接讀取，該4題依公開第三方轉錄核對，逐題揭露來源層級。**
- 選單可篩選短文／長文／既有12題，每道新題顯示改編來源、年份、題目定位、核實狀態、來源連結、難度與作答要求。題目情境及問法皆重新撰寫，**不是原試卷題目或學測原文**。
- 句子精修／段落深化／開頭結尾／完整作文共4種練習模式；完整作文模式對新增短文預設25分鐘、長文55分鐘，舊12題仍為90分鐘。此為本站練習配速，不是考選部逐題時間限制。
- 每題獨立草稿、計時、文字字數、草稿自動保存。
- 手動保存修訂版本（每題保留最多 40 個版本）、保留回饋、四項自我評估、下次目標。
- **v0.2 新增：** 以已保存的版本為基準，和目前正在修改的草稿左右對照；顯示字數差與首個差異位置，*不把字數成長視為寫作能力進步*。
- 一鍵複製 ChatGPT 批改提示詞；新增題目會包含短／長文類型、20／60分參考配分、改編來源、答題要求，並要求AI先從題幹獨立分析、具體訂正；如已保存初稿，仍可比較改寫。需自行貼到ChatGPT並手動保存回饋，沒有AI API或自動閱卷。

### 英文
- 原有 **20 題** 題號與已答紀錄保留，追加 **60 題** 原創題目，共 **80 題**：單字、文法、閱讀、克漏字。
- 每題英文、四選一選項、中文翻譯與中文解析，作答後顯示正確答案。
- **v0.2 新增：** 每日固定五題（臺灣日期；首次建立後當日固定）、錯題／待加強篩選、每次作答歷史紀錄。
- 「重新練習」只清除目前答案顯示，不會抹去作答歷史；統計使用**每題首次作答**正確率，避免反覆練習造成虛假的進步數字。
- 本輪仍是原創練習題，不宣稱與考選部正式命題或難度完全一致。

## 分科清除學習紀錄
- 在共同科目站的「學習紀錄與備份」頁面，分別提供「清除作文紀錄」與「清除原創80題紀錄」按鈕；原創80題練習區仍維持隱藏。
- 兩個操作都要求兩次確認，請先「匯出 JSON」備份，因清除後無法直接復原。
- 清除作文紀錄：刪除本模組所有作文草稿、修訂版本、批改回饋、自評與改進目標，但不碰原創80題作答與外部延伸紀錄。
- 清除原創80題紀錄：刪除既有80題答題紀錄、歷次作答及每日五題題單，不刪除原題庫、作文或外部延伸練習資料。
- 以上僅修改 `psd-common-subjects-v1` 中相應欄位，絕不清除其他本機儲存鍵，尤其不修改 Staresto 每日英文 `psd-staresto-daily-v04`；若要清除 Staresto，請到每日英文頁面單獨操作。

## 資料相容及備份
- 使用相同本機儲存鍵 `psd-common-subjects-v1`；v0.1 的作文草稿及英文 e0–e19 作答紀錄保留。
- v0.2 新增可選欄位 `englishHistory` 和 `dailySelections`，不更換原有 schema 版本，舊備份可匯入。
- JSON 匯出／匯入含現有作文、英文答案、英文作答歷史和每日五題紀錄。**匯入會取代本模組全部資料**，先匯出舊紀錄。
- 本模組與專業科目題庫、每日訓練、新聞資料保持分離；不同裝置、不同瀏覽器不能自動同步。

## 題庫來源及限制
- **司法特考三等**：第一批使用112、113、114年官方國文試卷PDF核對結果；第二批115年作文暫據公開第三方轉錄，另附官方試卷索引，未宣稱讀取其PDF；實作僅改編短文／長文核心能力，同一原題可發展多個不同情境，不代表收錄同等數量的原始試題。
- **學測國寫**：112年至115學年度大考中心之題型特色或評分原則說明，原始寫作材料、圖片、名人著作不搬入本站；只擷取可核對的命題核心能力後自編新情境。
- 題庫原題來源會逐題標示核對層級。「改編自」表示參考命題核心，不表示考選部或大考中心認證，也不保證116年會重複命題。
- 目前三批新增題目ID為 `essay-adapt-116-001` 至 `essay-adapt-116-120`；舊12題仍使用原本索引0–11與本機儲存鍵，新增題目只附加在第12–131索引，禁止在後續版本改變其順序。
- 改編文本屬本站新寫練習素材；國考／學測原卷及第三方著作均不因本站引用來源而成為GPL授權內容。

- 特別注意：115年司法特考雖可在考選部年度索引查詢到，但目前作文全文僅依第三方轉錄核對；題庫的4題均附「第三方轉錄」註記及原始公開核對頁，禁止標為已讀官方原卷PDF。對應短文依該年度原題註明250字內，其他模擬短文原則為本站自行設定350字內；二者均非普遍的官方短文字數規範。
- 來源資訊、題目ID唯一性、短長文分配、篩選、原作文草稿及修訂版本，均納入回歸驗收；未經官方命題機關授權，不得將本題庫稱作官方標準模擬試題。

## v0.3：接入 staresto-create 外部英文題庫
- 於「國考英文」頁下方提供作者網站的 **9 個外部資源入口**：學測／指考單字、學測／指考克漏字、閱讀理解、文意選填、篇章結構、字根字首單字輪與中譯英。
- 依本站 `englishHistory` **最後一次仍答錯** 的題型（單字、文法／克漏字、閱讀）提示優先補強資源。只是練習方向提示，不會直接替代司法特考應試準備。
- 點「開啟原站練習」將在新分頁進入作者網站。本站不會擷取、嵌入、複製或更新第三方題庫內容，也不會讀取外站分數。
- 點「我已完成一次」可以**手動登記**此資源的練習次數；並不代表系統驗證你已完成或通過。外站練習次數與本站80題的正確率完全分開。
- 手動紀錄存在原本的 `psd-common-subjects-v1` localStorage 中新增的可選 `externalPractice` 欄位，並隨本站 JSON 備份匯出／匯入；原先草稿、英文作答及題號不會改動。
- 本功能以**連結形式**尊重作者與題目原權利人的著作權。專案未確認可供其他網站複製改編的明確授權，因此不搬入第三方題目。若未來要將題目實際併入本站，須先確認原作者及題目權利人的許可與使用條件。
- 相關來源：[staresto-create](https://github.com/staresto-create) 與 [高中英文自學題庫](https://staresto-create.github.io/JCEE-vocab-questions/)。
- 驗收：`node common-subjects/test-v02.cjs` 和 `node common-subjects/test-staresto.cjs`。
