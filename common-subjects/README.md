# 國考英文＋作文練習（116年觀護人）

此模組獨立於 `v2.5/`、`study30/` 與既有專業科目題庫，進入點為 `common-subjects/index.html`。

## 試作功能
- 作文：12題原創題目、4種模式、計時、每題獨立草稿、自動保存、40次版本快照、自評與回饋存檔。
- 英文：20題原創選擇題（單字、文法、閱讀）、中文翻譯與解析、錯題篩選、重新練習。
- 學習紀錄：本裝置統計，以及 JSON 匯出／匯入。
- ChatGPT 批改：僅產生並複製指令，不會在背景呼叫任何 AI API。
- 無外部樣式庫、JavaScript CDN、伺服器資料上傳。

## 資料與限制
本模組使用瀏覽器 `localStorage` 的 `psd-common-subjects-v1` 鍵值，與主站原有紀錄分離；只有在使用者主動複製批改指令並貼到 ChatGPT 時，作文才會離開本機。請勿在作文中輸入少年個案識別資料、公務機密或其他不宜分享的資訊。

這是教育用途示範題庫，非考選部官方試題、正式評分或即時 AI 閱卷系統。不同裝置不會自動同步；請定期備份。尚未設置完整 PWA 離線安裝功能。公開網站由 GitHub Pages 的 `main` 分支發布；在功能分支提交並不等於已部署。
