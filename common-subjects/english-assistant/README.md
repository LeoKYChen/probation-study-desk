# Staresto v0.6 — 連結式英文學習助手（第一階段）

## 定位
依使用者2026-10-17確認的**精簡需求**：每天安排 Staresto 原站資源、每天學至少6個新單字、手動登記完成與答題成績，避免本站重複安排相同練習範圍。**不再複製或建立4,733題完整站內作答系統**。

頁面位於 `common-subjects/english-assistant/index.html`。GitHub Pages 正式網址待測試與使用者驗收通過後再合併正式分支。這個分支不變更主站首頁、原本的 v0.4/v0.5 介面、作文或專業科目資料。

## 已實作
- 以臺北時間產生當天固定任務；每天都有單字（先進原站完成指定年度第1–5或第6–10題，挑至少6個生字做筆記），其他題型按星期搭配文法、閱讀及文意選填。
- 指定**資源＋年度＋題號範圍／篇章識別**，避免使用原站的「隨機10題」，而非僅去重網站首頁網址。
- 手動記錄完成與選填正確題數；完成任務不再排入新題單，同一天重新開頁也不改排。
- 「已做過／找不到，換一份」：排除使用者在 v0.4 已練過、或原站不能定位的範圍，改排其他尚未安排的任務。
- 保存到單獨的 `psd-staresto-link-coach-v06` localStorage 鍵；提供 JSON 匯出備份（匯入及跨裝置同步尚未實作）。
- 不讀取外站 cookie、帳戶、分數，不執行外站腳本、不搬入第三方題目內容，也不修改任何其他 localStorage 鍵。

## 尚待核驗與已知限制
- **題號定位**：學測單字首頁支援從「歷屆試題」選年度，但自動跳到特定第1–5／6–10題尚未確認。文法／閱讀／文意選填的「第一組／第一篇」與原站各年度選單也需逐項實機驗收；找不到時只能改排，不能按完成。
- **重複定義**：自動排課排除本頁已分派、已完成及手動排除的穩定任務 ID；**不代表外站自行抽出的隨機題永不重複**。尚未自動讀取 v0.4 的668題舊紀錄，須由使用者點「換一份」排除之前做過的內容。這是階段性限制，不宣稱全面跨版本去重。
- **每日6個新單字**：目前是任務指引與使用者筆記，真正的字卡清單、去重及間隔複習屬第二階段，尚無自動生成六張單字卡。
- **離站練習成績**：僅能手動輸入，不能從 Staresto 網站直接抓取。
- **資料保存**：同一瀏覽器的 localStorage；無跨裝置同步。JSON 匯出提供備份但未提供匯入。
- 原本第一階段的 v0.6 全題庫審核 Draft PR #12 繼續保留，**不應與此精簡版混合或擅自合併**。

## 測試
`node common-subjects/english-assistant/test.cjs`

測試涵蓋：同日題單固定、日期切換、每天單字、排除已做舊題、完成記錄唯一、分數校驗、不重複排課、獨立儲存鍵及靜態語法。**自動測試不等於瀏覽器實際操作驗收**；尚未驗收 Staresto 網站個別題組深連結及手機操作。

- 第3階段：學習趨勢、弱點分析、安全 JSON 匯入與完整回歸驗收。
