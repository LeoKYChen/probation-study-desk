完整學習紀錄備份

手動 JSON 備份功能仍可不登入、不上傳資料，並可自行保存至私人 Google Drive。下方另有選用的 Firebase 測試同步，只有本人登入並確認後才會上傳支援的學習資料。

測試版｜Google Firebase 多裝置同步

預定全站同步基礎。此測試版涵蓋15 類既有 localStorage 模組及備考書桌 IndexedDB。其他未列入白名單的資料及背景自動同步尚未接通，仍不得宣稱全站已完全上線。沒有登入或確認時，既有備份及練習功能完全不變。

使用 Firebase Spark 免費方案，需自行建立 Firebase 專案並設定 Google 登入及 Firestore 規則。此頁使用公開 Web config，不需要雲端管理金鑰。不可上傳可識別少年個案、公務機密或私人敏感卷證。 Firestore 是由 Google 託管的資料庫，不是端對端加密的私人保險箱。請先確認資料可以合法存入私人雲端；若不確定，請保持免登入本機模式。
