# 觀護人學習平台｜完整 JSON 備份（第二階段測試版）

**本頁在 PR #33 的獨立測試站驗收前，不視為正式上線。**

正式功能設計：從相同網址、同一瀏覽器的本機資料一次匯出包含各模組紀錄的 JSON；到另一裝置下載此檔，經預覽和明確確認後安全合併。整個流程在瀏覽器端完成，**不接 Google Drive API、沒有伺服器上傳、沒有帳號**。

## 建議操作

1. 把所有正在編輯的作文／申論草稿儲存好，關閉其他練習分頁。
2. 到 `backup/`，點「下載完整學習紀錄 JSON」。**確認檔案真的存在**。
3. 自己將檔案上傳到**私人** Google Drive。
4. 另一裝置自行下載，開啟同一網站的 `backup/`、選檔、查看每一模組的新增數與衝突數。
5. 先下載另一裝置**匯入前的保護備份**，確認已保存、其他練習分頁已關閉，才執行安全合併。
6. 如有同日期／同題不同版本，原紀錄優先；到「下載衝突版本 JSON」另存備份版本。必要時以原單題介面人工核對、整理。

## 涵蓋內容

- 自訂AI批改提示詞（`psd-ai-custom-rules-v1`）：模式／考科的規則；不同組合可合併，同組合差異保留衝突版。

- 函授課程與排程（`psd-lecture-planner-v1`）：課程名稱、堂次、觀看進度、時間設定和已確認計畫；跨裝置同一堂進度不同時保留原記錄並另存衝突版本，不靜默覆寫。


- 專業科目每日30分鐘（含已持久化的四格草稿／AI 評語／自評／進度）、舊版 426 題紀錄與每日模擬題。
- 每日模擬題收藏、國文作文與隱藏的80題原創英文歷史。
- Staresto v0.6 單字／練習、v0.4 歷史紀錄（**只保留原有資料，不顯示舊版練習入口**）。
- 少年司法週報已讀、收藏與字級、考試倒數設定。
- 匯入過的不同答案（衝突版本）本身也會加入後續完整備份。

資料鍵與規則在 `unified-core.js` 的固定白名單中；**不掃描或備份整個網站任意 localStorage**，避免不必要資料及來源不明的鍵混入。原模組鍵不變。

## 特別注意

- GitHub Pages 與 Cloudflare 是不同網站來源：**各自儲存紀錄**。只在目前開啟網址讀取，若在兩邊寫過不同答案，請**各自匯出**，在目的網站依次匯入。
- 舊模組先前匯出的單獨 JSON 格式**不能直接用完整備份入口**讀取；請到原模組匯入，再在該網址匯出「完整紀錄」。
- 同日期的專業練習紀錄視為完整版本，不會擅自把兩個不同 session 的計時、題號、答案拼成同一筆。遇衝突另存一份原始版本。
- 匯入不會自動解決衝突，只會避免資料丟失；必要時另行下載衝突版 JSON，人工對照。
- 現有站點某些頁面的即時計時使用 `sessionStorage`，**跨分頁不能完整取得**；完成的題目、草稿與已保存紀錄才會在完整 JSON 內。
- 瀏覽器本身沒有可靠的方法得知使用者是否把下載成功保存到磁碟／iCloud。匯入前設有人工確認，請實際檢查檔案。
- 多個 localStorage 鍵無法由瀏覽器提供真正的資料庫交易，本工具逐個寫入並嘗試失敗回復；**仍應自行保留匯入前備份**，以防儲存空間耗盡或瀏覽器異常。
- 檔案最高 20MB；若超過限制或現有紀錄無法讀取，會停止匯出／匯入，提示保留原資料。
- JSON 中可能含個人文字、AI 回饋，甚至敏感內容；請**勿上傳公開 GitHub、任何公開分享連結或公開網路空間**。

## 2026-10-23｜第四區：清除學習紀錄

「清除」是**明確啟動的本機操作**，不會由排程或網頁載入時自動執行。流程：按「先下載清除前完整備份 JSON」→ 確認裝置確實保存 → 關閉編輯分頁並確認 → 鍵入「清除」→ 最後確認。

- 僅處理目前網址的已知學習／閱讀鍵：專業每日練習、v2.5／v2.4 與歷史考古題紀錄、每日模擬及收藏、作文與英文學習進度、少年司法週報收藏／已讀、歷史英文進度、衝突版本。
- 保留考試倒數、閱讀字級、AI 自訂批改提示詞與英文字詞自訂清單。函授保留課程名稱、堂次及讀書時間／排課規則，但觀看分鐘數歸零、已確認課表清除；完全沒有觀看進度的函授資料不重寫。
- 本功能不使用 `localStorage.clear()`，也不清理未知的其他網站儲存鍵。備考書桌使用獨立 IndexedDB，請至備考書桌的清除功能處理。
- 需要恢復時，可匯入清除前完整備份；既有匯入機制採保護本機原紀錄的安全合併。如果函授課程相同但觀看分鐘數不同，可能產生需人工核對的衝突版本，並非自動覆蓋。
- 畫面只顯示現行且實際有記錄的模組；**隱藏空白舊模組不等於刪除其資料**。匯出完整 JSON 仍保留原白名單中可辨識的歷史儲存內容。

相關驗收：`node backup/test.cjs`、`node backup/test-browser.cjs`（Playwright）。
