離線閱讀、作答與保存

這一頁協助你先在有網路時下載學習所需檔案，之後在同一台手機或電腦斷網閱讀已下載的題目、撰寫答案；文字仍存於原本的瀏覽器紀錄。外部網站、雲端 AI 及更新最新題庫需要網路。

① 先下載完整離線資料

點選上方的「離線使用」，再按「下載離線資料」。請等待所有檔案下載結束且顯示「離線已備妥」，不要中途關閉頁面。

目前下載範圍包含：專業科目練習、426 題考古題、125 題每日模擬題、國文作文及英文題庫、少年司法週報、JSON 備份頁面及 A4 列印中心。

特別提醒：離線資料不是你的私人答案備份。即使離線下載完成，也請定期在「完整學習紀錄備份」頁下載 JSON。瀏覽器網站資料若遭清除，題庫快取及私人答案可能一併消失。

② 飛航模式驗收

  1. 先在線上完成下載；回到這個頁面確認顯示「離線已備妥」。
  2. 關閉 Wi-Fi 與行動數據（或開飛航模式）。
  3. 重新開啟同一網址，分別點開一個考古題、每日模擬題及國文作文。
  4. 實際輸入幾個測試字，確認頁面顯示「已儲存」。關閉後重新開啟，檢查文字仍在。
  5. 恢復連線後，再從本裝置下載一份 JSON 備份。

離線快取屬於網站的 HTTPS 資料，不能保證在私人瀏覽模式、儲存空間不足、系統清理或更換瀏覽器後仍然存在。從 GitHub 與 Cloudflare 各自開啟時，需要各自下載，答案也不會自動互通。

④ 更新與資料保護

恢復連線後，可以從離線設定重新下載最新版資料。下載若失敗，系統應繼續保留上一份已完成的離線快取，不會清除你的私人作答。離線不代表跨裝置同步；若換手機或切換網址，請用第二階段 JSON 備份安全合併。

第五階段的「下載 GitHub ZIP、解壓縮、雙擊即可完全離線使用」是另一種安裝方式，本階段不包含。

本工具在瀏覽器內處理快取與本機紀錄，不連接 Google Drive API。少年司法法律資料及練習內容離線後可能不是最新版本，法律適用前請重新核對現行法規。
