# Staresto 全站資料收錄（獨立資料分支）

收錄計畫涵蓋 [staresto-create](https://github.com/staresto-create) 的全部 10 個公開 GitHub 儲存庫。**此分支不是練習站發佈版**，不更動目前 668 題的每日英文課程、國文作文及舊80題。

## 收錄原則

1. 以 2026-10-16 檢查的來源 commit 鎖定每個儲存庫，逐一驗證所有追蹤檔案的數量及 SHA256，產生 `library/manifest.json`。
2. 所有 JSON 教育資料保存原始內容，註明非商業個人／教學用途、作者署名及來源；所有 HTML 只擷取不可執行的可見文字存為 TXT。
3. 對於網站程式（JS/CSS）、圖像、音檔與其他不同權利性質的資源，**完整索引但不複製**；由明確的來源網址連到作者檔案，待合法重製範圍核對後再決定是否納入。
4. 原作者中譯、解析、標註等不因存放 GitHub 而改為本專案 GPL 授權。參考、試辦與研究用試題應保留原大考中心使用條件。
5. 本次「完整」指完整來源資源目錄及全部可依現有條件收錄的文字資料，**不是聲稱已獲得所有上游程式碼、MP3 或圖片的散布許可**。
6. 上游 HTML 不在主站同源執行，避免存取作文本機草稿、答題紀錄或其他 localStorage。

## 執行

GitHub Actions 工作流程 `.github/workflows/staresto-intake-catalog.yml` 會在本資料分支執行：

- 唯讀取得各來源鎖定版本；
- 對照所有檔案、驗證 JSON、抽出 HTML 文字並產生全檔名與雜湊目錄；
- 更新此資料分支的 `staresto-intake/library/`；
- 不產生任何正式站執行程式碼，也不合併 `main`。

執行後讀取 `library/CATALOG.md`，可查看來源數量及每個儲存庫的涵蓋程度。後續練習設計須另行討論、另案開發與測試。
