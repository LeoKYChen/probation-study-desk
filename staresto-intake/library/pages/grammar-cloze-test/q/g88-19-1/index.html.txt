88 年學測 克漏字 第19題
代名詞／指示詞線索：句內
I've only got the first two pages. 19 should be four more.
(A)They
(B)These
(C)Those
(D)There
答案：(D) There
題目編號：G88_19_1（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
【句型】There should be...存在句句型，表示「應該還有四頁」；They／These／Those 都是代名詞不是存在句結構，不符合這裡表達「應該還存在／還有」的語意。
深入解析
本題大考中心未公布逐題答對率，以下不談數據，只談觀念。
你可能會這樣想
前一句剛說 I've only got the first two pages（我只拿到前兩頁），所以你會覺得接下來要講「那些頁」怎麼樣，於是 They 或 Those 讀起來很順。但這一句要說的不是「那些頁如何」，是「應該還有四頁存在」。
怎麼判斷
四個選項裡三個是代名詞、一個是 There，可見這一格考的是這一句用什麼句型。先把句子讀完：___ should be four more.（應該還有四頁。）這是在說某樣東西的存在與數量，英文用的是存在句 There is／There are，加上助動詞就成了 There should be。掛鉤用 There is a book on the desk.（桌上有一本書。）。與 90 年第 17 題 →可以對照著看：那一格填的是 Here is，把一樣新東西端到眼前；本題填的是 There should be，講的是某樣東西應該存在。兩個都是把主詞挪到動詞後面的句型，考的都是「這一句在做什麼事」，不是文法對不對。
誘答選項
They：當主詞的話，句子變成「它們應該是另外四頁」，可是 they 只能指他已經收到的那兩頁，那兩頁不會是另外四頁。These、Those：同樣的問題，而且這兩個字通常要接名詞或有明確的所指，本句都沒有。
常考字詞與句型
There should be（應該有）、there is／there are …（有）、There seems to be（似乎有）、four more（另外四個）、check sth（核對某物）、right away（立刻）。
