110 年學測試辦考試 克漏字 第14題
字彙選義線索：句內
It should not be used when you ought to take responsibility; 14 should it be taken as an excuse for inaction.
(A)so
(B)nor
(C)only
(D)nearly
答案：(B) nor
題目編號：G110試辦考試_14_1（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
【句型】nor + 倒裝句，nor should it be taken...表示「也不應該被當作不作為的藉口」，nor 在這裡連接兩個否定概念（不應該用在該負責的場合；也不應該被當藉口），並引發部分倒裝（助動詞 should 提前）；so（如此，語意方向錯誤，so 應該接肯定句）、only（只是）、nearly（幾乎）都不合。
深入解析
本題大考中心未公布逐題答對率，以下不談數據，只談觀念。
你可能會這樣想
四個選項都是很短的功能詞，如果沒注意到空格後面的語序不對勁，會覺得 only 或 so 都能擺。這一格的線索是倒裝——空格後面的助動詞跑到主詞前面去了。
怎麼判斷
先看空格後面的語序：___ should it be taken as an excuse for inaction。主詞是 it、助動詞是 should，而 should 跑到 it 前面——這是倒裝。會逼出倒裝的，除了放在句首的否定或限制副詞，還有連接詞 nor（nor + 助動詞 + 主詞，劍橋 English Grammar Today）。四個選項裡能直接帶出倒裝、又接得上前面那個否定句的只有 nor，所以填 nor。再看語意：分號前面是 It should not be used when you ought to take responsibility（該負起責任的時候不該用它），是一個否定；nor 接著再加一個否定——「也不該把它當成不作為的藉口」。nor 的意思就是「也不」，它自帶否定，所以後面不能再放 not。nor 後面的倒裝，與否定副詞放句首造成的倒裝是同一種語序，這一類倒裝在題庫裡考過好幾種：Not until ...、No sooner ... than ...、Not only ... but also ...、Hardly ... when ...、Never／Seldom／Little，以及 Only + 副詞片語（86 年第 25 題 →的 Only by entering ... can a climber ...）；Not until 與 No sooner than 則是 95 年第 25 題 →的誘答選項。判斷方式永遠是同一句：先看主要子句有沒有倒裝，有倒裝就往這一類找。
誘答選項
so（所以）：後面接倒裝時意思是「……也是」（So do I.），但那要接在一個肯定句後面，而前半是否定句。only（只有）：Only 放句首確實會造成倒裝，但它後面要接副詞片語或子句（Only by ...、Only when ...），不能單獨擺著再接倒裝。nearly（幾乎）：一般的程度副詞，不會造成倒裝。
常考字詞與句型
nor + 倒裝（也不……）、neither + 倒裝（也不……）、So do I.（我也是）、take responsibility（負起責任）、an excuse for（……的藉口）、inaction（不作為）。
