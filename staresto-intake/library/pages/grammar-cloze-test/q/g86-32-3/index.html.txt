86 年學測 克漏字 第32題
介系詞線索：句內
Suddenly one of the young engineers gave what he thought was a good solution 32 the problem.
(A)of
(B)at
(C)to
(D)in
答案：(C) to
題目編號：G86_32_3（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
【句型】solution to a problem 指「問題的解決方案」；of／at／in 都不是 solution 常見的搭配介系詞。
深入解析
本題大考中心未公布逐題答對率，以下不談數據，只談觀念。
你可能會這樣想
四個都是最高頻的介系詞，中文「問題的解決辦法」裡那個「的」在英文裡對應到哪一個，中文完全幫不上忙。這一型只能靠有沒有把名詞和介系詞當一組記起來。
怎麼判斷
四個選項都是介系詞，可見這一格考的是 solution 跟哪一個搭配。答案是 solution to：a good solution to the problem 就是「這個問題的一個好辦法」。這一組值得整批記起來——中文都翻成「……的」，英文卻一律用 to：a solution to a problem（問題的解決辦法）、the answer to a question（問題的答案）、the key to success（成功的關鍵）、the approach to a subject（處理某主題的方法）。共同的語感是「指向某個目標或對象」，所以用 to。
誘答選項
of、at、in：三個都是高頻介系詞，但 solution 不與它們組成通行的說法。這一型文法上刷不掉任何一個，只能靠平常有沒有把整組記起來，所以背名詞時要連介系詞一起背。
常考字詞與句型
a solution to（……的解決辦法）、the answer to（……的答案）、the key to（……的關鍵）、solve a problem（解決問題）、come up with（想出）、find a solution（找出辦法）。其中 come up with 這一組考過 3 個年度，103 年第 29 題 →、110 年試辦考試第 15 題 →都出現過。
