84 年學測 克漏字 第35題
字彙選義線索：句內
In town, tourists can browse through 35 number of interesting shops, such as antique stores and the shop that sells items 36 from Oregon's beautiful myrtlewood.
(A)the
(B)this
(C)a
(D)that
答案：(C) a
題目編號：G84_35_2（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
【句型】a number of 是固定片語，表示「許多」；the／this／that 都不能這樣修飾 number of 構成「許多」的意思。
深入解析
本題大考中心未公布逐題答對率，以下不談數據，只談觀念。
你可能會這樣想
四個選項都是限定詞，而 the number of 是很常見的說法，看起來很眼熟，很容易反射性地挑 the。但那個說法的意思完全不同。
怎麼判斷
先看整句：tourists can browse through ___ number of interesting shops（遊客可以逛……有趣的商店）。要說的是「許多」，固定說法是 a number of（許多、若干）。這一組一定要分清楚，兩者的意思與動詞都不同：a number of + 複數名詞＝許多，重點在「多」，動詞用複數；the number of + 複數名詞＝……的數量，重點在「數量」這個單一概念，動詞用單數。本句是 browse through ___ number of shops（逛許多商店），不是「逛商店的數量」，所以填 a。順帶一提，86 年第 40 題 →考的正是同一個片語的另一個用法——那一題考的是主詞用 a number of 時動詞要用複數。同一個片語，一題考冠詞、一題考主謂一致，兩題可以對照著記。
誘答選項
the：the number of 是「……的數量」，語意不合。this、that：這兩個指示詞要指前面提過的某個特定數量，而本句是第一次提到這些商店，沒有可指的對象。
常考字詞與句型
a number of（許多）、the number of（……的數量）、browse through（隨意逛、瀏覽）、an antique store（古董店）、a large number of（大量的）、quite a few（相當多）。其中 a number of 這一組考過 4 個年度，86 年第 40 題 →、91 年補考第 26 題 →、98 年第 28 題 →都出現過；the number of 考過 3 個年度，86 年第 40 題 →、98 年第 28 題 →都出現過。
