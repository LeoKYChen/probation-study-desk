97 年學測 克漏字 第23題
時態／語態線索：句內答對率 61%
答對率 61%：當年每 100 位考生，有 61 位答對。
If he sold the stone, he thought, he 23 enough money for the rest of his life.
(A)had
(B)had had
(C)would have
(D)would have had
答案：(C) would have
題目編號：G97_23_2（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
這一句是 he thought 帶出的轉述：他當時想的是 If I sell the stone, I will have enough money，放進過去的敘述裡，if 子句與主要子句各往前推一格，成了 If he sold ..., he would have ...，主要子句用 would + 原形動詞，表示「如果他賣了這顆寶石，他這輩子就衣食無缺了」；had（單純過去式，變成在敘述已成事實的「他有足夠的錢」）、had had（過去完成式，句中沒有更早的參照點）、would have had（配的是 If he had sold 那種與過去事實相反的假設，與這裡的 If he sold 對不齊）都不合。
深入解析
你可能會這樣想
看到 would have，你可能會反射性把它接成 would have + 過去分詞，覺得後面應該再來一個過去分詞，於是改挑 would have had。這裡要看清楚一件事：would have enough money 的 have 不是完成式的助動詞，它就是動詞本身，意思是「擁有」，後面接的是名詞 enough money，不是過去分詞。
怎麼判斷
先看 if 子句：If he sold the stone 用的是過去式。這一句夾著 he thought，是旅人當時心裡的想法：他想的是 If I sell the stone, I will have enough money.（如果我把寶石賣掉，錢就夠了。）放進過去的敘述裡，if 子句與主要子句各往前推一格，就成了 If he sold the stone, he would have enough money。還原驗算：把 he thought 拿掉，時態推回原來的 sell 與 will have，讀起來完全通順。轉述時 will 變 would 的最短版本是 He said he would come.（他說他會來。）主要子句是 would + 原形，本題的原形就是 have（擁有）。這一格鑑別度只有 31，偏低，連高分群考生也會失手，原因有兩個：一是 he thought 插在 if 子句與主要子句中間，把句子切斷，讀的時候容易以為時態要再往過去推一層；二是 would have 這兩個字連在一起，長得太像 would have + 過去分詞的前半截，對這個組合越敏感的人，反而越容易多想一步。110 年第 25 題 →與 114 年第 11 題 →考的都是 would have + 過去分詞，可以拿來與本題對照：那兩題後面接的是貨真價實的過去分詞，本題接的是名詞。
誘答選項
had：把主要子句寫成單純的過去式，變成在敘述事實「他有足夠的錢」，但他還沒賣掉寶石，不合事實。had had：過去完成式，需要一個更早的過去參照點，句中沒有。would have had：這是與過去事實相反的假設，要配的 if 子句必須是 If he had sold the stone（過去完成式）；本題的 if 子句是 If he sold（過去式），兩邊搭不起來。判斷方法很單純：if 子句往前推一格，主要子句就得往前推一格，兩邊要對齊。
常考字詞與句型
If + 過去式, 主詞 + would + 原形動詞（與現在事實相反的假設；在過去的敘述裡轉述 If + 現在式, 主詞 + will + 原形動詞 的條件句時，也是這個形態，本題就是）、If + had + 過去分詞, 主詞 + would have + 過去分詞（與過去事實相反的假設）、for the rest of one's life（一輩子、餘生）、have enough money（有足夠的錢）、sell sth（賣掉某物）、come back to find sb（回來找某人）。
