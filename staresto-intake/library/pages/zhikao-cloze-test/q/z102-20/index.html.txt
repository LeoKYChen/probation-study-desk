102 年指考 克漏字 第20題
連接詞／轉折詞線索：句內答對率 80%
答對率 80%：當年每 100 位考生，有 80 位答對。
Post offices would remain open on Saturdays 20 customers can drop off mail or packages, buy postage stamps, or access their post office boxes.
(A)so that
(B)as soon as
(C)in case
(D)ever since
答案：(A) so that
題目編號：Z102_20（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
【連接詞】so that 引導目的子句，表示「郵局週六仍開放，以便讓顧客可以……」。as soon as（一…就）、in case（以防萬一）、ever since（自從）都不符合此處的目的語境。
深入解析
你可能會這樣想
四個選項都由兩三個字組成、後面也都接子句，形態上刷不掉，你會一個一個代進去讀讀看。
怎麼判斷
這是邏輯勾環：要判斷的是前後兩件事之間的邏輯關係。前半是郵局週六仍照常開門，後半是民眾可以寄信寄包裹、買郵票、開自己的郵政信箱——後半正是前半的目的，開門就是為了讓民眾辦得成這些事。表目的的連接詞是 so that，而且它帶出的子句裡通常會有 can、could、may、will 這類助動詞，本句的 can 正好是它的標記。填進去讀成 remain open on Saturdays so that customers can drop off mail（週六仍開門，好讓民眾可以寄件）。
誘答選項
as soon as（一……就……）標示的是時間先後，但民眾辦事並不是郵局一開門就發生的某個單一事件；in case（以防萬一）後面要接的是想預防的狀況，民眾能寄信不是要預防的事，方向相反；ever since（自從……以來）後面接一個過去的起點，主要子句通常用完成式，本句講的是未來的安排。
常考字詞與句型
so that + S + can／will（以便、好讓……）、in order that（以便）、in case（以防萬一）、as soon as（一……就……）、drop off（順道送去、放下）、remain open（維持營業、仍舊開著）。
