94 年指考 克漏字 第23題
關係子句／疑問詞線索：句內答對率 53%
答對率 53%：當年每 100 位考生，有 53 位答對。
It is held in unknown, guarded warehouses 23 only a few people can see it.
(A)which
(B)where
(C)until
(D)unless
答案：(B) where
題目編號：Z94_23（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
where 引導形容詞子句修飾地方先行詞 warehouses，表示「在那些倉庫裡，只有少數人能看到它」。which 需要子句中扮演主詞/受詞角色，此處子句已是完整句子不缺成分，故不合；until（直到）、unless（除非）都不符合修飾地點的語法功能。
深入解析
你可能會這樣想
which 與 where 都能接在表示地方的名詞後面引導關係子句，你會憑語感挑一個。
怎麼判斷
鑑別度高達 61。關係詞的題目有一個方法最可靠：把先行詞代回子句裡，看它在子句裡以什麼形式出現，就用對應的那一個關係詞。這一題的先行詞是 unknown, guarded warehouses（不為人知、有人看守的倉庫），子句是 only a few people can see it。把倉庫代回去，句子要寫成 only a few people can see it in the warehouses——倉庫在子句裡是「在倉庫裡」這個地方副詞，既不是主詞也不是受詞，前面還得補一個介系詞。代回去變成地方副詞的，就用關係副詞 where。填進去讀成 It is held in unknown, guarded warehouses where only a few people can see it。這個方法之所以可靠，是因為它連 whose 都涵蓋得住：the boy whose father is a doctor，把先行詞代回子句是 the boy's father is a doctor，出現的形式是所有格 the boy's，所以用 whose。代回去長什麼樣就用哪一個：當主詞用 who 或 which、當受詞用 whom 或 which、變成所有格用 whose、變成地方副詞用 where、變成時間副詞用 when。
誘答選項
which 是關係代名詞，代回去要能直接當主詞或受詞；但這一句代回去是 see it in the warehouses，倉庫前面少不了那個 in，所以 which 接不上（要用也得寫成 in which）。until（直到）與 unless（除非）是連接詞，填進去語意也不通——「直到只有少數人看得到」「除非只有少數人看得到」都不成句意。
常考字詞與句型
where（關係副詞，先行詞代回子句後變成地方副詞）、whose（關係代名詞的所有格，代回子句後變成所有格）、in which 等於 where（在其中）、the reason why …（……的原因）、be held in（被存放在）、a few（少數幾個）。

中譯：全世界最大的高棉雕塑收藏，坐落於柬埔寨舊王都吳哥。這 7,000 件文物——包括完整雕像、頭像與雕刻銘文——不只因其個別之美令人屏息，更因為它們所代表的意義而令人驚嘆：那是一幅通往東南亞文化根源的路線圖。然而，這批收藏並不是陳列在博物館裡，也不對外開放參觀，而是被存放在不對外公開、戒備森嚴的倉庫裡，只有極少數人能夠一睹真容。這些人將原本的雕像從柬埔寨舉世聞名的寺廟遺跡中取出，再換上中空的水泥複製品，這些複製品大多難以與原件區分。是狡猾的文物竊賊嗎？不，這些「文物竊賊」其實是替吳哥保育組織工作的人員。除了少數過於龐大、難以搬動的作品之外，幾乎所有留存至今的吳哥雕像、木雕與文物，都已被複製品所取代。
