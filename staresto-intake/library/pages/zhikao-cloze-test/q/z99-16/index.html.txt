99 年指考 克漏字 第16題
慣用語／片語線索：句內答對率 37%
答對率 37%：當年每 100 位考生，有 37 位答對。
But one special sculpture gallery invites art lovers to allow their hands to 16 the works.
(A)fix up
(B)run over
(C)take away
(D)knock off
答案：(B) run over
題目編號：Z99_16（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
run over 在此意為「（手）掠過、撫過」：這座特別的雕塑展區邀請愛好者用手撫過作品；fix up（修理、安排）、take away（拿走）、knock off（打掉、下班）語意都不合。
深入解析
你可能會這樣想
run over 你大概只想到「輾過」（The dog was run over by a car.），所以覺得放在這裡很奇怪。其實 run 的核心是「移動、掠過」，主詞換成手或眼睛時，意思就是「輕輕掠過、快速看過」：She ran her fingers over the keyboard.（她的手指掠過鍵盤）／Let me run over the main points again.（讓我再快速複習一次重點）。
怎麼判斷
線索是整段的對比：前一句說羅浮宮到處都是「請勿觸摸」的告示；本句用 But 轉折，說有一個展區反而邀請大家動手。下一句說明那是 the Tactile Gallery（觸覺展區），為視障者而設，是館內唯一可以觸摸的空間。既然主題是「用手觸摸」，動作自然是手在作品上撫過。Cambridge 字典在 run 的詞條裡就有這個用法：If you run your finger or hand over something, you move it quickly.（手或手指在某物上掠過），例句是 She ran her fingers along the edge of the desk.（她的手指沿著桌緣滑過）。
誘答選項
fix up：修理、安排，博物館不會請參觀者動手「修理」作品。take away：拿走，前一句說館內到處都是「請勿觸摸」的告示，館方更不會邀請人把作品拿走。knock off：下班、打掉、（俚語）偷走，沒有一個意思接 the works 說得通；展區要的是「觸摸」，不是把作品弄掉。
常考字詞與句型
run one's fingers over（用手指掠過）、run over the main points（快速複習重點）、be run over by a car（被車輾過）、keep one's hands off（別碰）。
