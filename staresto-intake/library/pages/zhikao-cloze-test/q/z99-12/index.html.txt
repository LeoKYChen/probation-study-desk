99 年指考 克漏字 第12題
句型結構線索：句內答對率 70%
答對率 70%：當年每 100 位考生，有 70 位答對。
If we used more of this source of heat and light, it 12 all the power needed throughout the world.
(A)supplies
(B)has supplied
(C)was supplying
(D)could supply
答案：(D) could supply
題目編號：Z99_12（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
與現在事實相反的假設語氣：If + 過去式（used）, 主要子句用 could/would + 原形動詞，could supply 符合這種假設語氣的公式。supplies（直述句現在式）、has supplied（現在完成式）、was supplying（過去進行式）都不符合假設語氣的動詞形式配對。
深入解析
你可能會這樣想
看到 If 你大概直接讀成「如果……就……」，順手填一個現在式進去；但這一句的 If 子句用的是過去式 used，那正是一個訊號。
怎麼判斷
鑑別度高達 58，分開的是有沒有先看 If 子句的動詞形態。If 子句寫的是 used（過去式），可是講的並不是過去的事——太陽現在就在那裡，是我們現在沒有多用它。這就是與現在事實相反的假設語氣：動詞倒推一個時態，現在的事改用過去式，公式是 If + 過去式，主要子句用 would／could／might + 原形動詞。常見的例子是 If I were you, I would tell him.（我不可能是你，所以 were 配 would）。四個選項裡只有 could supply 符合這個形態，填進去讀成 it could supply all the power needed throughout the world（它就能供應全世界所需的電力）。
誘答選項
supplies 是現在式，會把整句讀成單純的條件句，與 If 子句的過去式對不上；has supplied 是現在完成式、was supplying 是過去進行式，兩個都在陳述已經發生或當時正在發生的事實，與「假設」剛好相反。三個都是 supply 的形態，形態吻合，容易被順手選走。
常考字詞與句型
If + 過去式，S + would／could + 原形動詞（與現在事實相反的假設語氣）、If I were you（如果我是你）、supply A with B（供應 A 以 B）、harness energy（利用、駕馭能源）、throughout the world（全世界）、all the power needed（所需的全部電力）。

中譯：太陽是極其強大的能量來源。事實上，地球從太陽接收到的能量是我們目前所使用能量的兩萬倍。如果我們能善加利用這種熱與光的來源，它就能供應全世界所需要的所有電力。我們可以透過許多方式擷取太陽的能量（即太陽能）。舉例來說，太空中許多人造衛星裝有大型太陽能板，其太陽能電池能將陽光直接轉換成電力。這些太陽能板覆有玻璃，內部塗成黑色以盡量吸收熱能。太陽能有很多優點。首先，它是乾淨的燃料。相較之下，石油、煤炭等化石燃料燃燒時會釋放有害物質到空氣中。而且，化石燃料終將用盡，但太陽能會持續照射地球，即使在最後一塊煤被開採完、最後一口油井枯竭之後仍會繼續存在。
