101 年指考 克漏字 第19題
慣用語／片語線索：句內答對率 54%
答對率 54%：當年每 100 位考生，有 54 位答對。
The Italians, in panic, 19 the main exit in their section when a six-foot concrete wall collapsed.
(A)headed for
(B)backed up
(C)called out
(D)passed on
答案：(A) headed for
題目編號：Z101_19（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
headed for the main exit（朝主要出口奔去）表示義大利球迷驚慌之下衝向出口，此時一道六英呎高的水泥牆倒塌；backed up（回堵、滯留／支援）、called out（大喊）、passed on（傳遞）都不符合此處衝向出口的語境。
深入解析
你可能會這樣想
四個選項都是動詞加上介系詞或介副詞的片語動詞，形態很像，你會一個一個把中文代進去讀。
怎麼判斷
鑑別度高達 55。先看空格後面接的是什麼：the main exit（該區的主要出口），是一個地點。再看主詞與情境：The Italians, in panic（義大利球迷驚慌之下）——人在慌亂中，對著一個出口能做的事就是往那裡衝。四個選項裡只有 head for 是「朝……而去、前往」，後面接的正是目的地，填進去讀成 headed for the main exit（朝主要出口衝過去）。head 當名詞是「頭」，當動詞就是「把頭朝向那邊走過去」，兩個意思接得起來。
誘答選項
back up（支援；倒車；備份）後面接的是被支援的人或資料，不是地點；call out（大聲呼喊）後面接的是喊出來的話或被叫的人；pass on（傳遞下去）後面接的是被傳遞的東西。三個都是片語動詞，形態吻合，容易被順手選走，但把 the main exit 放進去都讀不成句子該有的意思。
常考字詞與句型
head for（朝……而去、前往）、in panic（驚慌之下）、back up（支援；倒車）、call out（大聲呼喊）、pass on（傳遞下去）、collapse（倒塌、崩塌）。
