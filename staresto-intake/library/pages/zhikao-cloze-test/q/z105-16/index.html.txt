He was also the man who cracked the 16 uncrackable Enigma code used by Nazi Germany.
(A)eventually
(B)precisely
(C)concernedly
(D)supposedly
答案：(D) supposedly
題目編號：Z105_16（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
supposedly 意為「據稱、一般認為」，帶有「說話的人未必相信」的意味：他破解了那套「據稱無法破解」的恩尼格瑪密碼；eventually（最終）、precisely（精確地）、concernedly（關切地）語意都不合。
深入解析
你可能會這樣想
supposedly 這個副詞你可能不常見到，而且它的作用很微妙——它不是在陳述事實，而是在標示「別人是這麼說的，但未必是真的」。
怎麼判斷
本句的趣味就在這裡：the supposedly uncrackable Enigma code ＝「那套據稱無法破解的密碼」。既然圖靈把它破解了，uncrackable（無法破解）顯然只是「大家以為」而已——supposedly 就是用來標記這個落差。少了它，句子會變成「他破解了無法破解的密碼」，自相矛盾。看到形容詞前面要填副詞、而那個形容詞又與句子的事實衝突時，就要想到這類「據稱」的字：supposedly、allegedly（據稱，多用於指控）、reportedly（據報導）、seemingly（看似）。
誘答選項
eventually：最終，是講時間先後的副詞，修飾動詞或整句（He eventually succeeded.），不用來修飾形容詞 uncrackable；就算硬放進去，「最終無法破解」也與 cracked 矛盾。precisely：精確地、正是，放在形容詞前面是加強語氣，the precisely uncrackable code 等於強調「真的無法破解」，與圖靈破解了它直接衝突。concernedly：擔憂地，形容人的神態或做事的方式，密碼「無法破解」這件事不會「擔憂地」發生。
常考字詞與句型
supposedly + 形容詞（據稱…的）、allegedly（據稱，多用於指控）、reportedly（據報導）、be supposed to（應該）、crack a code（破解密碼）。
