答對率 28%：當年每 100 位考生，有 28 位答對。
However, this generally 20 when only a single or a few nails are affected.
(A)indicates
(B)defines
(C)applies
(D)confirms
答案：(C) applies
題目編號：Z107_20（已自動幫你填到回報表單裡）🚩 回報這題有問題
解析
apply 在此是「適用」：不過這種說法通常只適用於單一或少數指甲受影響的情況；indicates（顯示）、defines（定義）、confirms（證實）語意都不合。
深入解析
你可能會這樣想
apply 你大概只熟 apply for a job（申請工作），很少看到它單獨用來表示「適用、成立」。四個選項的中文擺在一起都像那麼回事，你會想憑語意挑一個順的，但這一題句法就先淘汰了三個。
怎麼判斷
先看空格後面有沒有受詞。this generally ___ when only a single or a few nails are affected——空格後面直接接 when 引導的副詞子句，沒有任何名詞當受詞。indicate、define、confirm 三個在這裡都是及物用法，一定要有受詞（indicate a problem、define a term、confirm a booking），少了受詞句子就不完整。apply 則可以不及物，單獨表示「適用、成立」：This rule applies to everyone.（這條規則適用於所有人。）／The same applies here.（這裡也一樣。）這一步已經可以初步鎖定答案，再用文意確認方向。本句以 However 起頭，作用是限縮前面那個結論的適用範圍——前面說白點會隨著指甲長出去、不必治療，這一句補上「不過通常只在少數指甲受影響時才成立」，下一句接著講十指全是白點的情況，正好是被排除在外的那一種。驗算法：把 apply 換成 be true 唸一遍——this is generally true when only a few nails are affected，意思不變，代換成立。
誘答選項
三個在這裡都是及物用法，錯在缺受詞，語意也各自不合。indicate 是「顯示、指出」，要說「顯示什麼」，而且顯示的是徵兆與結論的關係，不是適用範圍。define 是「定義」，後面接被定義的字詞，本句沒有東西要下定義。confirm 是「證實」，後面接被證實的說法或安排；而且 However 這個轉折要的是限縮，不是證實，方向也相反。
常考字詞與句型
apply to（適用於）、The same applies.（同理適用）、apply for a job（求職）、apply pressure（施加壓力）、indicate（顯示）、confirm（證實）、application（申請；應用）。
線索範圍說明：this 指前一句「白點會長出去、不再出現」的結論；下一句 If all of your nails… 的對比才界定適用範圍

中譯：許多人一生中都曾在指甲上出現白色斑點，其中最常見的原因之一是一種稱為「白甲症」（leukonychia）的病症。雖然這個名稱聽起來相當嚴重，但這種狀況通常並不嚴重。此外，許多人認為白斑是缺鈣或缺鋅所致，但事實通常不是這樣。
實際上，這些斑點多半是指甲受到輕度到中度的創傷所造成。如果你想不起指甲曾受過什麼傷，別忘了指甲生長速度非常緩慢，因此受傷後可能要經過數週，斑點才會顯現出來。這些斑點也可能是輕微感染、過敏，或某些藥物副作用的徵兆。
不論受傷的原因是什麼，這些斑點通常不需要治療，會隨著指甲生長而自然消失，除非指甲再次受傷，否則不會復發。不過，這個現象通常只適用於一片或少數幾片指甲受影響的情況。如果所有指甲都出現白斑，白甲症則可能與貧血、心臟病、糖尿病或腎臟病等更嚴重的病症有關。
