# 少年司法週報

公開網址：https://leokychen.github.io/probation-study-desk/juvenile-news/

提供週次查閱、四大主題分類、搜尋、來源與實務分析、收藏、已讀、字級調整及 Markdown 下載。週報資料在 issues.json；瀏覽器收藏與閱讀紀錄僅保存在本裝置。

原始碼在 source/。本 repository 沿用 main 根目錄的 GitHub Pages 發布方式；不另設 Pages 工作流程，不更改既有練習臺路徑。

每週研究排程在完成資料查讀後，保留既有期別並更新 juvenile-news/issues.json；同時同步 juvenile-news/source/public/issues.json。使用目前 GitHub 檔案 SHA 進行條件更新，讀回驗證後等既有 Pages 發布流程完成。

創刊期為重新編製的公开來源分析，不代表已匯入歷史對話週報原文。來源、日期與閱讀範圍均逐篇列明。其他私人文件、作答、憑證不属于週報公開資料。

介面開發：在 source/ 執行 npm install、npm run check、npm run build；將 source/docs/ 產物複製到 juvenile-news/，保留 README.md 與 source/。只更新 issues.json 不需要重新編譯。
