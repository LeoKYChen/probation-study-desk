# v2.7 × MCP｜第 3 階段第十二輪（Stage 3l）：跨裁判日期、長篇全文及官方格式相容性

**獨立分支**：`experiment/v27-mcp-stage3l`，從第十一輪 `experiment/v27-mcp-stage3k` 延伸。

## 目的與前一輪驗收邊界

前輪已有：
- 10 件既有公開民刑事裁判之來源、裁判日期、案號及 MCP 文字擷取一致性各 10／10；
- 10 件歷審清單官方逐欄對照 10／10；
- 27 個歷審項目中，限定的不同關聯裁判可回查性 7／7。
  
但最早 10 件父裁判都集中於 **2025 年 12 月 31 日**，且官方正文多來自 `.htmlcontent`。即使這些分項都完成，也不足以證明較早年份、超長文本、不同 HTML 版型或純 PDF 文件可以穩定由 MCP 擷取。

## 本輪有界測試

| 類型 | 指定來源／年份 | 單輪上限 |
| --- | --- | ---: |
| 高院民事 | 臺灣高等法院；民國 111 年；損害賠償 | 最多 3 件候選、通過至多 2 件 |
| 高院刑事 | 臺灣高等法院臺中分院；民國 112 年；詐欺 | 最多 3 件候選、通過至多 2 件 |
| 地院民事 | 臺灣臺北地方法院；民國 113 年；租賃 | 最多 3 件候選、通過至多 2 件 |
| 地院刑事 | 臺灣臺中地方法院；民國 114 年；詐欺 | 最多 3 件候選、通過至多 2 件 |

**總額度：4 個限定搜尋、最多 12 個直接官方裁判 GET、最多 8 次 MCP `get_judgment`。** 不檢索非公開少年事件，不新增非官方搜尋來源，不下載 PDF，也不繞過官網存取限制。固定使用既有研究版 `lawchat-oss/mcp-taiwan-legal-db`，commit `ef677ad63c3206fc211a083fad8b1d9ef5015222`。MCP 上游自身可能有連線復原機制；本輪未增寫任何繞過方法，並不代表此第三方搜尋即為正式官方 API 授權。

### 文字比對

每筆候選須先於官方頁面確認：
1. 來源是司法院 `judgment.judicial.gov.tw` 的指定 HTTPS 網頁；
2. 當次頁面的法院、裁判字號、案件類型、裁判日期均與搜尋結果的 JID 相符；
3. 有實質官方正文，且不是空殼 HTML；
4. 只有在符合以上條件後，才將官方 `#jud`／正文區塊與 MCP `full_text` 正規化全文比較。須「整個官方容器完全一致」或「官方正文完全一致」，不能僅用數段抽樣判定；
5. 正文長度至少 **10,000 個正規化字元**，才列為本輪「長篇文本」候選；長篇本身仍須通過完整一致性比對。

### PDF 及不同 HTML 格式

官方 HTML 擷取型態分為：
- `html_htmlcontent`：具實質的 `.htmlcontent` 內容；
- `html_text-pre`：具實質的 `.text-pre` 內容；
- `html_jud_content`：具實質的 `.jud_content` 內容；
- `html_with_pdf_reference`：HTML 中另有 PDF 指向，**未判定 PDF 完整性**；
- `pdf_link_without_verifiable_html_body`：只有 PDF 連結、未有可獨立核對的完整 HTML 正文；
- 其他未支援／無正文類型。

**PDF 相關頁面永遠不能因有連結、片段預覽或 HTTP 200 就取得「全文已驗證」標記。** 本輪只測試辨識及拒絕誤判的保護，不下載 PDF、不作 PDF 文字擷取、也不宣告 PDF 模式已受支援。若本輪未實際遇到 PDF，必須區分「合成規則測試通過」與「真實 PDF 來源未覆蓋」。

## 不能越界宣告的項目

- 官方網頁當次可讀不等於裁判此後持續公開、已確定或全部歷審完整；
- 「來源有 PDF」不表示來源或實際 PDF 檔已完成授權及內容驗證；
- 一般法院公開民刑事案件仍可能涉及當事人或未成年人敏感內容。本輪不記錄或輸出個案全文及姓名，卻不能以此推定永久資料蒐集、訓練或個資再利用均合法；
- 本輪樣本均從指定公開法院檢索結果取得，不憑空創造真實案號。每件檢查結果只記錄**群組、年別、公開日期、字數、格式類型、布林通過項目與錯誤分類**；不將實際 JID、連結、案名、正文、當事人或 PDF bytes 寫入程式庫及產物；
- 沒有官方開放 API 帳密、沒有雲端部署、沒有改 `main`、v2.5、`development/v2.7/`、`services/v2.7-judgment/` 或 Cloudflare。

## 完成判定

- **不同年份及 HTML 全文子測試**：至少 3 個不同西元年份成功由官方確認，至少 4 件跨組候選在 MCP 全文擷取一致性通過；不足即保留 review。
- **長篇子測試**：至少 1 件官方正文正規化字數達 10,000 且 MCP 擷取完整一致；沒有符合條件就保留 review。
- **PDF 子測試**：只有合成偵測器的正反樣本檢查，真實 PDF 全文若未獨立擷取比對，無論 GitHub Actions 綠勾與否一律**尚未驗收**。
- **第 3 階段整體**：真正的裁判確定、來源撤除／更新、全年 24 小時點擊時查核及完整備份清除等均未驗證，故 `stage3_accepted=false`、`all_formats_validated=false`。
