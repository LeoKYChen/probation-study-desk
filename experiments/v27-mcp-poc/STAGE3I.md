# v2.7 × MCP｜第 3 階段第九輪（3i）：跨法院公開裁判來源與文字忠實性抽樣

**分支**：`experiment/v27-mcp-stage3i`，從已通過兩件最高法院文字擷取驗證的 Stage 3h 開始。

## 目標與抽樣

第八輪已完成的兩件最高法院刑事裁定（114 年度台抗字第 2605、2657 號）**不再次查核**。本輪試著從真正的司法院公開搜尋結果，挑選**最多另外 8 件**，以覆蓋其他法院層級、刑民事與 HTML 格式：

| 組別 | 法院及系統 | 合法公開檢索範圍 | 最多通過 |
| --- | --- | --- | ---: |
| H-CIV | 臺灣高等法院；民事 | 民國 113–114 年，損害賠償 | 2 |
| D-CIV | 臺灣臺北地方法院；民事 | 民國 113–114 年，租賃 | 2 |
| H-CRM | 臺灣高等法院臺中分院；刑事 | 民國 113–114 年，上訴駁回 | 2 |
| D-CRM | 臺灣臺中地方法院；刑事 | 民國 113–114 年，詐欺 | 2 |

**不得把「8 件目標」當成一定找得到 8 件。** 任何搜尋無結果、逾時、官方頁面無法獨立核對，均保留為 review；不能自造 JID。明確排除少年及家事專門法院的識別碼，不查詢未公開少年裁判；一般法院的公開民刑事判決如果內容另涉未成年人，仍待個別法遵與使用範圍審查，不能自動當作任何個資使用已獲授權。

## 方法

- MCP 搜尋最多 **4 次**、每次搜尋結果最多 **5 筆**，每組最多 2 件，指定法院與民刑事類別；除非另經使用者同意，否則本輪不加大規模，不繞過封鎖。
- 直接官方 HTTP GET 最多 20 個且有限制請求時間／回應大小；來源必須符合司法院 HTTPS 網域、精確 `ty=JD&id=JID`。
- 搜尋結果不能直接算正式來源。只有官方頁面可讀到與法院、案號、年別相符的實質正文時，才把公開 JID 記入測試報告。
- 再以固定上游 `lawchat-oss/mcp-taiwan-legal-db`、SHA `ef677ad63c3206fc211a083fad8b1d9ef5015222` 取回同 JID；核對官方完整內容容器是否與 MCP 正規化後文字完全相同、官方正文是否完整包含於其中。
- **抽樣文本一致性通過**：只表示「這次取回的官方 HTML 與 MCP 擷取文字一致」，不等於裁判已確定、沒有撤除風險，亦非法律見解正確性或完整歷審驗收。
- 不寫入原始 HTML、正文、姓名、身分資料、判決摘要、附件、PDF、任何會保留內文的快取至 GitHub；CI 只保存公開來源 JID、網域／來源、字元長度、證據布林值與錯誤分類。
- 不使用司法院授權開放 API 帳號或 Token，亦不對正式 v2.5／v2.7 網站部署任何檢索服務。

## 必須區分的驗收

1. **檢索找到候選案號**：只要結果來自真實搜尋，但還不能證明官網全文存在。
2. **官網可驗證公開來源**：官方頁面能獨立確認法院、案號與本文，才能記為本輪已識別來源。
3. **MCP 擷取文字忠實性**：與上述官方全文容器完全相同，或完整忠實擷取正文；不能用抽樣 8/9 取代嚴格原文驗收。
4. **實際現行公開狀態及歷審、撤除、更新**：仍需另一套可信、可用的正式機制，不能由本輪已通過的文字一致性推定。

原訂第 3 階段完整驗收要件包含：至少 10 件不同真實公開裁判的來源及文字核對、歷審及更新／撤除安全機制、正式授權及實際保留政策。**本輪不自動宣告第 3 階段通過，也不合併到正式站。**
