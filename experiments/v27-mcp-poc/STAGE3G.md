## 二、本輪具體實作

### 來源途徑小量實測（GitHub Actions）

`stage3g_official_source_probe.py` 最多只發出 **4 個 GET**：

1. 官方裁判書系統說明頁（是否為可辨識的官方 HTML）。
2. 官方 API 規格檔案（HTTP200 之外需有 PDF 標頭）。
3. 第三階段先前已由公開搜尋實際取得的一件最高法院成人刑事裁判 JID：`TPSM,114,台抗,2605,20251231,1`。
4. 同樣先前實際找到的第二件公開裁判：`TPSM,114,台抗,2657,20251231,1`。

技術限制：
- 不進行自動登入、**不呼叫** `/jdg/api/Auth`、`JList`、`JDoc`；不做需要帳密的操作。
- 單一請求、不可跨網域重新導向、不重試、不繞過網站防護、限制回應長度及請求時間。遇連線限制直接記 `review`。
- 個別裁判頁面即使 HTTP200，也須具有可辨識的裁判正文區塊、法院、案號及內容，才能列為「待獨立全文複核的候選」。**即使發現正文，仍不可直接列為正式已核對，也不核准對外個別深連結**。
- 測試報告不保留任何官網 HTML、裁判全文、姓名、當事人資訊、PDF 內容或衍生摘要。只記錄路由類型、HTTP 狀態及是否有足夠官方內容的布林證據。

### 臺灣時間及可靠性閘門

`stage3g-official-source-gate.cjs` 模擬實際官方 API 取用限制：

- 臺灣時間 00:00～05:59：只有在事先取得資料平台帳號授權、核對使用規範並**另經明確核准**的前提下，才有資格安排低流量 API 真實測試（本程式並不執行）。
- 臺灣時間 06:00～23:59：官方 API 非服務時間，不能以該 API 提供使用者點擊時的即時查核。
- 官方 `JList` 是**固定七日前的異動清單**，不是目前仍公開的裁判完整清單；不得藉此宣稱完整歷審、裁判確定或仍公開。
- 官網 HTTP200 或第三方 MCP 的快取結果，若沒有獨立原文與公開性查核，不能核准個案深連結。
- 一律不開放自動儲存裁判全文，也不核准個別深連結。系統可以保留司法院裁判書系統通用查詢入口。

## 三、驗收關卡

1. GitHub Actions 中純合成的來源閘門測試及既有回歸測試須全數成功。
2. 官方可用性檢查最多 4 個 GET；來源資料可取得才標記相對應 `passed`，不能把 API 文件可取得誤認為實際 API 已驗證。
3. 任何個別裁判頁面只能列為 `review`，直到同時具備獨立全文核對及當下公開狀態的查核證明。
4. 若官方網站拒絕連線或返回只有介面的 HTTP200，記錄限制，**不以網站擷取繞過方式反覆嘗試**。
5. 第 3 階段仍須完成原訂的 10 件公開裁判的來源、全文及撤除機制驗收；在此之前不併入正式站。

## 四、將來要提供真正的裁判檢索，還缺哪些？

第一個選項是 **不接真實裁判：只提供司法院官方通用查詢入口**。可立即維持低成本、無裁判資料保存的網站。

第二個選項是待使用者有意願後，**另行註冊司法院資料開放平臺會員**，自行安全設定帳密，再規劃凌晨時段少量驗證。即使 API 取用成功，網站若要全天候提供個案深連結，仍須處理**非服務時段無法即時重新查核**、裁判撤除同步及個資／日誌問題。此階段不索取帳密、不啟用真實 API。

**禁止以 100% 綠燈的合成測試結果代替上述正式授權、可靠性與法律驗收。**
