# v2.7 × MCP｜第 3 階段第三輪（3c）：官方裁判 API 異動與撤除安全試點

**作業原則：只有純合成資料、只有 GitHub Actions 受限環境、沒有真實司法院 API 呼叫。**
分支：`experiment/v27-mcp-stage3c`；基於 `experiment/v27-mcp-stage3b` 建立。不修改 v2.7 網站及 v2.5 正式站，也不改既有私有裁判服務。

## 官方來源與必須落實的約束

司法院《裁判書開放 API 規格說明》（114年8月22日版）：https://opendata.judicial.gov.tw/api/Newses/42/file

1. Auth 以平台帳密取得 Token，效期 6 小時；服務時段為 **臺灣時間00:00～06:00**。
2. JList 回傳**查詢當天七日前**的裁判異動 JID，不是即時清單，亦不是歷年全量資料。
3. 同一 JID 再次取得可能有修改版，須覆蓋舊版。
4. JDoc 回傳「查無資料，本裁判可能未公開或已從系統移除……」時，使用者必須處理既有儲存資料刪除；此訊息與網路逾時、驗證失敗不能混淆。
5. JFULLX 為物件：text 的 JFULLCONTENT 才可視為文字全文；file 型式有官方 PDF URL 時，文字內容不能被自動當成完整正文。

## 這一輪實際建置的內容

**檔案：** `stage3c-synthetic-delta.cjs` 及 `stage3c-synthetic-delta.test.cjs`。

這是**不可用於真實 JID 的測試協調器**，會拒絕任何不符合 `TEST_JID_SYNTHETIC_...` 的識別碼。它透過現存 `judicial-api-client.cjs` 的注入式假 HTTP transport 模擬 Auth → JList → JDoc，再串接現存的兩個獨立**記憶體** SQLite/D1 模擬資料庫、撤除墓碑及外部版本見證函式。

安全流程：
- 檢查獨立撤除紀錄及版本見證健康；任何異常直接停止。
- 依臺灣時區計算 T-7 日；異動清單格式或日期不符，不變更任何資料。
- 只允許上限 20 件**合成案件**，先取得所有 JDoc 回應並驗證格式，避免一半更新後才發現另一半壞掉。
- 撤除優先：寫入獨立墓碑→推進測試版本見證→封鎖操作庫→清除當前主表、搜尋索引、摘要、向量參考→驗證當前資料表。
- 更新其次：把 JDoc 轉成**不含全文、PDF、預覽或附件**的合成中繼資料，經獨立撤除門檻寫入私有資料庫，防止已撤除資料再次匯入。
- 公開查詢仍恆為空；所有執行報告沒有真實案號、當事人、正文或帳密。

## 判定與風險

這一輪可驗證的是：
- 以假資料重現官方 JList/JDoc 的「更新、撤除、非撤除錯誤」三種流程；
- 官方移除通知不與連線錯誤混同；
- 異動日期、舊版重複識別碼、錯誤憑證、存取門檻、兩庫隔離、撤除後禁止重匯；
- JFULLX file 只有預覽時，不誤存成文字全文。

**本輪不能驗證：**
- 司法院官方 API 的真實回應、機關憑證與授權條件；
- 從現在到過去的完整裁判全量索引或漏抓七日前清單的補回方案；
- 雲端正式 D1／R2／CDN／搜尋引擎索引／備份及 Time Travel 的實際完整清除；
- 官方資料撤除是否能於法律及技術要求時間內完成；
- 裁判歷審狀態、法院判決內容與原始官網逐字比對；
- 撤除日誌的**外部不可回滾可信版本見證**（現在只是測試注入）；
- 對外開放查詢；沒有任何授權或部署核准。

即使「live rows」已清除，**D1 Time Travel／備份／快取仍未查核，不可稱為完全刪除**；故 `withdrawal_fully_verified`、`stage3_accepted` 必須保持 `false`。

## 第三輪驗收

1. GitHub Actions 可以完成 Node.js 24 安裝、所有合成測試與既有 `services/v2.7-judgment/*.test.cjs` 回歸測試。
2. 同一 JID 新版覆蓋舊版、官方移除後不可重新匯入、未受影響之其他 JID 繼續保持隔離。
3. JList 非 T-7、非合成 JID、錯誤 Auth／JDoc、撤除庫版本倒退，均不得產生公開或部分匯入結果。
4. 現有 Worker 仍拒絕所有 HTTP 請求，Cloudflare Pages 中無私有裁判元件與秘密資訊。
5. 測試成功才可稱「**離線模擬安全流程通過**」；第 3 階段實際公開裁判的全量驗收仍保留未通過。

## 下一項正式依賴（不在本輪啟用）

如果將來要接入真實 API，必須另外完成最小授權連線測試、可信獨立見證、滯後七天異動的補漏機制、可驗證的完整撤除與備份保留政策，以及實際裁判公開身分與來源再驗證；不得直接複製本試驗協調器上線。
