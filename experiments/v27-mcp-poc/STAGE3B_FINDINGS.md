- **不能**在此基礎上認定兩件裁判與官網正文已逐字相符，更不能啟用公共網站的裁判全文檢索或快取。

## 下一輪應如何調整？

1. **保留既有 5 項進一步核對成果**，不再重跑立法理由及憲法裁判的相同基本案例，除非版本或來源更新。
2. **裁判全文比對改採來源可靠性優先**：評估合法的司法院公開資料取得途徑（官方授權 API／資料下載規則）。若需帳號，先完成帳密隔離與撤除機制，再由使用者決定是否申請；不得將帳密置於聊天或公開 GitHub。
3. 精確案號搜尋已證明有效，但尚未證明十件不同裁判的正確性。未經官方獨立核對，不擴大成「10/10 裁判驗收通過」。
4. 將官方資料撤除、版本變更、快取失效、歷審未完結、來源網站封鎖視為獨立的安全／品質閘門；任何一項不能確認，應顯示待複核，而不是捏造內容或隱藏風險。
5. 第三階段的正式驗收仍按原計畫要求不少於十件公開裁判樣本及五件憲法／立法材料的可追溯核對，並有完整撤除保護，不能只看 GitHub Actions 綠勾。
