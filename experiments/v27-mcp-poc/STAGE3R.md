# v2.7 × MCP｜第 3 階段第十八輪（Stage 3r）：法規及函釋來源分級顯示

**日期：2026-10-17（臺灣時間）**  
**開發分支：`experiment/v27-mcp-stage3r`**，基於已完成的 `experiment/v27-mcp-stage3q`。

## 一、目的

將前輪的「功能分級驗收與上線阻擋」往使用者可閱讀、可操作的 UI 前進，但**不觸及正式 v2.5／原 v2.7 站點**，也不增加 PDF 轉存功能。針對容易混淆的資料來源，建立一個**完全合成、只在本機顯示的法規／函釋 UI**，並以 Stage3q 只讀證據表防止虛報。

### 保留的既有結論（本輪沒有重新驗收官方資料）

- 第 1 階段：**20/20** 指定公開法規檢核項目通過；法律修正公布日、施行日與條文過渡規定尚不能混同；2026-10-02 官方快照並非後續全部修正的即時法律版本。
- 第 2 階段：**21/21 中繼資料；17/21 官方全文；4/21 僅官方要旨**。使用者採 B 方案承認「依官方實際公開程度」的限定驗收，**不是** 21/21 全文已驗。
- 所有指定函釋的**現行法律效力尚未查核**；站方摘要不等於官方原始要旨。
- 第 3 階段整體及真實裁判 PDF 的資料更新／撤除驗收均未通過。

## 二、本輪介面實作

`stage3r-demo/index.html` 是可單獨離線打開的 HTML：
- 頂部保留既有抽樣成果的 20/20、17/21、4/21 歷史說明，**每筆卡片均是合成示例，不聲稱是前述已驗官方個案**。
- 提供三個可操作分類：全部資料、法規版本、行政函釋。
- 法規卡片分開顯示**來源快照日／修正公布日／施行日**。即使合成記錄填了施行日，仍明確表示「未依即時官方資料核對是否現行有效」；沒有施行日不得從修正日自行填補。
- 函釋卡片提供「完整官方全文層級的**合成示範**」「僅官方要旨層級的**合成示範**」「內容未取得」三種。無要旨時不能偽稱全文；即使合成輸入含一段冒稱全文的文字，函釋被分類為 `official_abstract_only` 時也**絕不顯示冒稱全文**。
- 站方摘要獨立呈現，清楚標示非官方要旨；即使使用者輸入 `validity=valid` 也不能推定函釋現行有效。
- 針對手機、桌面及鍵盤操作製作響應式卡片與 `aria-pressed` 分類鍵；實際文字使用 DOM `textContent`，不使用 `innerHTML` 插入外部內容。
- CSP 限定站內相對檔案，禁止外部網路請求、嵌入 iframe／object、上傳表單與 inline 執行程式。

## 三、檔案分工

| 檔案 | 用途 |
| --- | --- |
| `stage3r-demo/index.html` | 只讀離線 UI，包含來源限制說明與分類操作 |
| `stage3r-demo/style.css` | 桌機與手機斷點下的卡片樣式 |
| `stage3r-demo/model.js` | Node／Browser 雙用的合成記錄分級、日期欄位、來源等級與失效預設 |
| `stage3r-demo/app.js` | 不連線的五筆人工合成示範、分類按鈕與 `textContent` 渲染 |
| `stage3r-demo/model.test.cjs` | 來源等級、日期、匯入相容、內容注入、上線阻擋等測試 |
| `stage3r-demo/package.json` | 單獨 CommonJS package scope，避免受 repo 根目錄 Vite ESM 設定影響 |
| `stage3r-demo/README.md` | 離線使用方式與必要驗收邊界 |

## 四、此輪**沒有建立**的功能

- 沒有讀取真實法規條文、21 件實際函釋文字或其官方網址。
- 沒有對所有法條進行現行生效版本核對，也沒有替四件僅有官方要旨的函釋「創造」全文。
- 沒有實際介接 v2.7 UI／API、法規更新排程、函釋現行效力、司法個案資料、PDF 轉存、文件上傳或 AI 判斷引擎。
- 沒有使用真實裁判、少年案件卷證、帳密、Token、付費雲端環境或 Cloudflare。
- **沒有授權正式發布或合併**。所有 `productionApproved`、`stage3Accepted`、`fromOfficialData` 等可靠性欄位一律保留 `false`；樣本合成 `contentLevel` 只是畫面示意，不能當可信後端來源認證。
