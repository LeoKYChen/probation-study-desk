## 二、官網原始依據

### 1. 政府資料標準平臺

官方：[法制 > 法規 > 法規中文](https://schema.gov.tw/lists/96)。

實際查到的**政府資料標準英文字段**包括：

- `StatName`：法規名稱。
- `StatURL`：法規網址。
- `StatModifiedDate`：**法規最近一次異動日期**，部分法規可能異動月份或日期不詳。
- `StatEffectiveDate`：**法規生效日期**。
- `StatAbandonNote`：廢止註記（廢）。
- `StatContentType`：逐條型（01）或單篇型（02）。
- `StatContent`：單篇型內容。
- `StatArticles`：逐條型法條集合。
- `ArticleType`：章節（C）與一般條文（A）。
- `ArticleNo`：條號（例如 15-1）。
- `ArticleContent`：條文內容。

上述為官方**資料標準**欄位及型別定義。**本輪未下載真正法務部法律 XML 檔並檢查原始節點**，因此不得逕稱 `StatModifiedDate` 等一定是實際下載 XML 中同名標籤。

[政府資料開放平臺的法務部法律資料集](https://data.gov.tw/dataset/18289) 確認有 XML 與 ZIP 資源，資料集欄位包括法規名稱、網址、最近異動、生效日期及內容，來源為法務部資訊處；登載更新頻率為每月，授權採政府資料開放授權條款第 1 版。更新頻率不是某個法律條文現行施行狀態的證明。

### 2. 法務部公開函釋網頁

官方：[法務部主管法規查詢系統公開行政函釋範例](https://mojlaw.moj.gov.tw/LawContentExShow.aspx?id=FE315630&media=print&type=e)。

本輪以該**一般公開、且非先前 21 件指定驗收樣本**的函釋頁面確認「發文單位」「發文字號」「發文日期」「要旨」等文字標示確實存在。頁面實際也可能同時出現「主旨」「說明」等公文段落，但**不能用有標示、有文字就推定整份原始公文（含附件／其他版本）均已完整核實**。

尤其因本輪只保存公開頁面**標示是否存在的數量**，沒有存原始網頁、文號、公文本文、要旨或法律結論。官方函釋的現行效力仍獨立列為未知，不以「查詢頁可開啟」推論適用中。

## 三、實際新增程式及驗收重點

### `stage3t/official-field-mapper.cjs`

**限定合成資料進入研究用轉換器**，新增以下錯誤降級規則：

1. `StatModifiedDate` 應對應 **latestChangeCandidate**，**絕不可直接寫進「修正公布日」**；即使生效日欄存在，也不得推論個別條文施行日。
2. `StatEffectiveDate` 對應 **statuteEffectiveMetadataCandidate**，不能任意推論特定條文或個案行為時的施行與過渡適用。
3. 官方資料標準指出部分異動日期有年月日不詳的可能，僅有年月或日期不合法時一律保留 `null`，不自動補零或改成該月一日。
4. `StatContentType` 的逐條／單篇不可混用；`ArticleType=C` 章節不可當成 `ArticleType=A` 一般條文。
5. 僅接受精確的 HTTPS 法務部域名及預期的研究來源 URL 形狀，惡意偽冒網域、帳密、token 及不合法查詢參數均拒絕。
6. 含「發文單位／文號／日期／要旨」的函釋候選**不能因頁面另有主旨／說明而自動升級成官網全文已完整核實**；也不能將站方摘要冒充官方要旨。
7. 使用者自行加入「已驗證」「現行有效」「正式授權」旗標，無法跳過來源查核或部署阻擋。任何候選輸出皆不含實際公文原文或可直接公開的個別連結。

`status=schema_candidate_unverified` 是刻意保留的**研究用候選狀態**，不是最終可上線的可信資料。

### `stage3t/official-field-mapper.test.cjs`

**49／49 項通過**：修正異動／施行概念、曆法有效性、日期不全、廢止註記、逐條／單篇內容、章節編碼、網址偽裝、函釋全文與要旨差異，以及惡意或無憑據的「已驗證」旗標。

### `stage3t/public-label-probe.py`

僅讀取事前限定的兩個一般公開網頁（**非會員、非司法裁判、非少年事件**）。有單次回應大小限制、無自動重新導向、限制連線逾時；真正網頁文字與來源網址不保存到 CI JSON。任何無法連線、阻擋或標籤缺漏，均應 `review` 而非自行認定成功。

本輪實際：

- 法規公開頁面：**HTTP 200，3／3 個預定欄位標示存在**。
- 行政函釋公開頁面：**HTTP 200，4／4 個預定欄位標示存在**。
- 兩者都不表示「全文獨立核對成功」，亦無現在仍有效、當下全部法規更新或真實 XML 解析的證據。

## 四、仍未通過的正式接入門檻

1. **真實下載 XML 內容的元素名稱、巢狀結構及欄位值**尚未解析或驗收。官方資料標準名稱不能自動取代 raw XML/JSON 結構。
2. 官方法規最新版本、**修正公布日期的獨立來源**、生效日期與個別條款施行／過渡規定的對應關係，需另行逐件核對。
3. 對原先 21 件函釋，仍依 Stage2 限定結論**17 件官網全文、4 件僅官網要旨**處理；本輪未核對新全文，也沒有解決現行適用效力。
4. 本輪的實際網頁探查只確定文字標示存在，**不曾測試正式的 HTML DOM selector／parser 對欄位值的忠實解析**。
5. 尚無正式來源授權、快取更新、撤除或版本生命週期驗收，尤其不能因此讓未公開少年裁判或真實 PDF 取得權限。
6. 第 3 階段整體仍不通過，亦不得直接與 v2.5 或原有 v2.7 上線版本整合。
