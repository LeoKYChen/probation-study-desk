## 四、限制與禁止事項

- **未重新執行**已在第八、九輪通過的 10 件全文擷取逐字比較；本輪只在官網頁面確認基本可讀，再取得官方歷審資料及 MCP 清單。
- 不下載歷審關聯裁判全文；不把歷審說明、正文、當事人姓名、案情、附件及其他關聯裁判 JID 保存到 GitHub 檔案／CI 報告。
- 只在獨立 GitHub Actions 臨時環境執行研究版 MCP，未使用正式司法開放 API 帳密、授權或 Token。
- 不將歷審比對通過視為裁判已確定；尤其沒有獨立檢查歷審各個連結是否仍公開。
- 本輪來源限 2025-12-31 的既有 10 件樣本，尚未證明其他裁判日期、版型、長篇文書或 PDF 類型均可用。
- **沒有修改** `development/v2.7/`、`services/v2.7-judgment/`、`main`、v2.5 及 Cloudflare，也沒有公開任何個別裁判檢索端點。
