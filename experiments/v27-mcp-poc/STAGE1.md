## 這次測試到底測什麼？

20 筆獨立案例：

- S01–S12：共 12 條現行法條，與 v2.7 已保留、由全國法規資料庫開放資料取得的 **2026-10-02 快照**比對文字。
- E13–E14：查詢舊站未收錄的《中華民國刑法》第320條與《刑事訴訟法》第95條。這兩筆先核對 pcode、條號、來源和特徵字句，**僅能標為待獨立官方全文複核**。
- A15–A16：驗證「少事法」、「刑法」的法規簡稱轉換。
- R17：第3條之1至第3條之4的區間查詢，逐條比較既有官方快照。
- N18：不存在的法規必須回報失敗，不得編造條文。
- O19：只查法規目錄時不得冒稱已取得指定條文。
- H20：查詢第3條之1的歷次修法資訊。**歷史條文未逐版本與官方來源核對前，這筆只列待複核。**

## 分數與驗收

- `passed`：達成這一案例已定義的客觀檢查。
- `review`：初步查到，但尚未完成必要的官方全文／歷史版本複核。
- `failed`：找不到、來源不符、內容不符或格式錯誤。CI 會產生紅叉及報告，不得略過。
- 單純 `GitHub Actions success` 只代表腳本完成且沒有偵測到明確錯誤；不代表本階段已通過全部法律正確性驗收。
- 完整階段驗收仍需：20項均執行、通過至少18項、**所有已展示法律內容來源正確、不發生混用版本或捏造**，完成額外法律與歷史條文官方逐字核對，且快照版本狀態確認。
- 只要有 `review` 或沒有查核官方最新資料，`stage1_accepted` 必定為 `false`。

## 來源限制及後續改進

原站的 223 筆快照是官方資料，但來源日期為 2026-10-02，不能用來直接證明 2026-10-15 當天的現行法完整正確；差異可能是法規修正，也可能是擷取錯誤。差異不得自動視為新版正確，更不得自動蓋掉 v2.7。

案件失敗及待核對結果分開記錄，下載 GitHub Actions artifact `v27-mcp-stage1-accuracy-report`，查每個案例的狀態與原因；不保存案件個資，不產生真實少年裁判資料。

當對照測試足夠穩定後，下一輪才評估以**另一條獨立官方法源比對途徑**核對完整歷史與施行日期，並重新計算正式驗收門檻。
