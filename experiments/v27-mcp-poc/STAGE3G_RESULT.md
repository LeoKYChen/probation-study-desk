## 第一項：官方來源性質及使用規範

1. [司法院裁判書開放 API 規格說明（114.08.22 版）](https://opendata.judicial.gov.tw/api/Newses/42/file)：Auth 需會員帳密及 Token；JList 僅回傳查詢日**七日前**異動 JID；JDoc 回傳全文；API 服務時間為臺灣時間 **00:00–06:00**；原資料可能修改、撤除，遇明定的撤除訊息須刪除已取得裁判。
2. [司法院開放資料使用規範（司法院公報第63卷第1期）](https://www.judicial.gov.tw/tw/communique/dl-115081-23e72637eb1d41f7b7606d097f3f0a52.html)：區分一般及會員開放資料；資料使用者須遵循資料取得方式、註明來源、維護資料正確性、按公告異動所取用的會員資料，並兼顧第三人權益。
3. [司法院裁判書系統說明](https://judgment.judicial.gov.tw/readme.aspx)：官方網站為使用者查詢入口，有其收錄／公開範圍與限制。

**架構判斷：** 以每日凌晨 API 同步取得的 `JList`，不能充作全天候的個案點擊時「即時公開狀態」證明。官方 API 非服務時段沒有可用的即時查核；HTML 網頁偶能取得正文，不代表有穩定、允許大量自動化介接的官方服務承諾。第三方 MCP 研究工具的網站連線手段應另行審核，不能視為官方授權的實際 API。

## 第四項：真實使用的安全閘門

`stage3g-official-source-gate.cjs` 僅做離線可用性判斷：

- 臺灣時間 00:00–05:59，即使未來完成會員註冊，仍須使用者明確授權才可能安排真實 API 測試。
- 臺灣時間 06:00–23:59，不可宣稱能靠官方 API 執行點擊時立即查核。
- 官網 HTTP 200、無裁判正文、案號／法院不符或沒有獨立原文比對，一律不放行個別裁判連結。
- 即使全文重疊或完全一致，也不能直接推定判決已確定、歷審完整、此刻仍公開或符合撤除義務。
- 本輪不要求帳號、密碼、付費、部署或正式合併。

當真實來源的全天候公開確認仍不可行時，網站維持僅提供司法院**通用裁判書查詢入口**，不得以合成流程代替真實核對。
