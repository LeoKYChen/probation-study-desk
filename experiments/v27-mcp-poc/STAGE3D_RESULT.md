### 明確保留問題

1. 目前所有資料均為**合成**；新協調器刻意拒絕真實 JID。它**不能**作為現成網站裁判搜尋後端。
2. 可信的獨立司法院頁面查核端點尚未解決；上輪直接官方網頁雖回 HTTP200，卻沒有取得足以獨立核對的裁判正文。
3. 尚未實作**使用者每次點擊個別連結之前的再次查核**；本輪只保證產生模擬連結時，合成證據在指定五分鐘內。已顯示的舊連結無法自動收回。因此個別裁判深連結功能**尚不能上線**。
4. 只提供連結仍可能記錄案號、JID、搜尋詞及點擊日誌，不能當成不處理個資或已完成撤除義務。
5. 尚未驗證真實裁判公開與歷審、判決全文、撤除與備份處置，也沒有官方 API 授權／真實 API 呼叫。
6. 無任何 Cloudflare Worker、D1、R2 部署。現有 v2.5 及 v2.7 原測試站未修改。
