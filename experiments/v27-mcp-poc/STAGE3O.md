# v2.7 × MCP｜第 3 階段第十五輪（Stage 3o）PDF「可視版面 × 文字層」雙重驗證

**開發分支：** `experiment/v27-mcp-stage3o`（以第十四輪 `experiment/v27-mcp-stage3n` 為基礎）。  
**範圍：** 只處理由本輪程式合成、沒有個人資料的 PDF。**無真實司法院 PDF、無下載、無使用者上傳、無 OCR、無官方 API，亦不對外發布個別裁判連結。**

## 一、為何需要這一輪

前一輪已完成 PDF 檔頭、頁數、頁序、合成案號、文字擷取與逐頁合成文字參考的安全檢查（40/40 通過）；然而 PDF 內可能存在**肉眼看到的文字與機器讀到的文字層不一致**，例如：

- 文字層真的包含內容，但使用白色字顯示在白底、遭到白色矩形遮蔽，或位於裁切頁面之外。
- 表格欄位內容的顯示位置互換，但機器依原繪圖命令順序讀出相同的文字。
- 只有圖片掃描頁，畫面上有字，PDF 文字層卻是空的；沒有可信 OCR 就不能說文字擷取完整。
- PDF 本文出現新的可視標示／覆蓋，並非機器文字擷取所能反映。

上述問題會影響判決理由、主文、表格或證據順序的法律解讀。不能只因 `extract_text()` 沒報錯，就認定與原始裁判一致。

## 二、Stage3o 的有界技術架構

`stage3o_visual_gate.py` 使用既有 `stage3n_pdf_gate.inspect_synthetic_pdf()` 作**第一道文字驗證**，只在前一道合成檢查完全通過時進入第二道：

1. 將合成 PDF 每頁透過 **PyMuPDF 1.26.7** 的固定光柵渲染器（RGB、倍率 1.25、無註記）轉為記憶體像素；
2. 在**測試環境**以另一份事先製作的正常合成 PDF，建立每頁寬、高及 RGB 像素的 SHA-256 比對憑據；
3. 對比每頁像素尺寸與 SHA-256，**只要任何一頁不同便保留 `review`**；
4. 必須合成逐頁文字與合成參考逐頁畫面**同時**一致，才回傳 `synthetic_visual_and_text_passed`；
5. 檢查輸出只有理由代碼與數量，**不輸出 PDF bytes、圖片像素、頁面文字或案件識別碼**。

程式設有多項限額：借用 Stage3n 的 PDF **450 KB**、最多 **12 頁**限制；渲染時每頁最大 2,500,000 像素、整份最大 20,000,000 像素，且檢查參考圖像的尺寸與雜湊格式。

## 三、測試情境及正確的攔截結果

- 正常單頁／多頁合成 PDF：須逐頁文字與像素全部匹配；
- 缺少參考圖、參考頁數不符、圖像 hash 不合法或頁面尺寸不符：`review`／`blocked`；
- **白字白底、白色矩形遮蓋、整頁覆蓋、字的位置改變**：即使文字層與預期完全相同，畫面比較仍須不通過；
- **表格格線被移除、表格兩個欄位的可視位置交換**：即使文字抽取次序不變，畫面比較仍須不通過；
- **實際由合成點陣影像產生的「掃描式 PDF」**：因沒有可信文字層，須停在第一道文字驗證，**不自動執行 OCR**；
- PDF 裁切區域縮小：若不可視部分仍可由文字層抽出，須由畫面尺寸／渲染結果差異發現；
- PDF 文字內容遭篡改：在第一道文字驗證即拒絕，不應先依畫面比較放行。

## 四、這個原型的根本限制（尤其重要）

**同一份有缺陷的 PDF，如果拿它本身產生參考畫面，再跟自己比較，結果依然可能一致。** 因此：

- 本輪的 `synthetic_reference_from_fixture()` 僅供**離線測試夾具**建立已知正常的參考；不能直接當成司法機關獨立授權的證據。
- 像素 SHA-256 是**畫面同一性比對**，不是圖像語意辨認或 OCR，也不具備「與真實裁判文字相同」的獨立證明力。
- 渲染結果可能隨 PDF 引擎版本、字型環境、色彩管理和平台改變；測試因此固定工具版本、渲染比例及色彩設定。對正式 PDF 直接採用逐像素完全一致，可能造成合法版本排版差異的偽陰性。
- 即使實際文字與參考畫面同時一致，也不能據此認定整份裁判已確定、歷審完整、仍公開、PDF 來源獲授權，或後續撤除已完成清除。
- `pypdf`、PyMuPDF 不是不受惡意 PDF 影響的安全沙箱；缺乏**每份檔案獨立限時、限 CPU／RAM、網路隔離和資料生命週期管理**，不能開放使用者上傳任意 PDF。
- **本輪不會用 OCR 搜尋或補寫任何真實司法文書**，更不會以文字層一致性或像素相同來推定法律內容正確。

## 五、部署隔離及下一步

程式和測試均位於 `experiments/v27-mcp-poc/`，工作流程為 `.github/workflows/test-v27-mcp-stage3o.yml`，沒有修改 v2.5、原 `development/v2.7/`、`services/v2.7-judgment/`、`main` 或 Cloudflare。

正式 PDF 測試仍缺**官方核准取得途徑、可信的獨立裁判原文／頁面參考、可執行的個資及撤除政策、受限 PDF 解析沙箱**。這些條件未具備前，網站對 PDF 類型維持：

**「官方來源可能有 PDF；全文尚未核實，請至司法院官網確認。」**

`real_official_pdf_fulltext_verified=false`、`stage3_accepted=false` 保持不變。
