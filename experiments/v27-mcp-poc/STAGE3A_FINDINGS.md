## 工程判斷

1. 憲法裁判三例可以回到官方公開頁面，是工具來源可追溯性證明；**不是裁判全文內容無誤的證明**。
2. 立法理由兩例 MCP 都有回傳版本資訊，但仍須與立法院原始逐版本理由核對；只檢查來源網站 HTTP 200 不足以驗證理由。
3. 公開裁判書 3 個議題中，2 組成功取得公開裁判正文、1 組關鍵字搜尋逾時。下一輪**優先改善精確案號查詢、縮小查詢範圍及失敗處理**，避免對司法院過度反覆發出廣泛請求。
4. 只有通過官方個別裁判頁面與內容／日期／法院核對、歷審完整性標示及撤除保護的裁判，才可納入後續固定測試樣本；不可自行虛構十個案號。
5. GitHub Actions success 不等於第 3 階段成功。當前輸出 `stage3_accepted=false` 是正確的關卡設計。
