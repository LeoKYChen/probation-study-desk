## 一、本輪實際交付的功能

新增 `experiments/v27-mcp-poc/stage3r-demo/` 離線網頁，使用人工合成資料，包含：

- **2 張合成法規卡**：分別標示來源快照日、修正公布日與施行日；一張刻意不提供施行日，另一張提供純合成施行日。兩種情況均保留「現行版本／施行規定尚待官方核對」。
- **3 張合成行政函釋卡**：分別示範 `official_full_text_verified`、`official_abstract_only`、`unavailable` 的資料層級。標示「官網全文欄位」「官方要旨欄位」只是**介面假設值**，本輪沒有對該合成個案取得真正官網文字。
- 另外顯示「本站自行編寫摘要」，和官方來源層級分開；**官方僅要旨時，合成資料中縱使額外放入冒稱全文的字串，畫面也不會將其展示為官方全文**。
- 法規／函釋／全部三分類切換，以及手機與桌面的響應式卡片佈局。
- 完全離線、無外部資料 API、無 iframe、無使用者上傳、無 PDF 轉存或司法個案深連結；UI 以 DOM `textContent` 顯示示範文字，並使用限制網路連線的 CSP。

## 五、如何使用

自獨立分支下載 `stage3r-demo/` 同目錄的四個檔案：`index.html`、`model.js`、`app.js`、`style.css`，在電腦瀏覽器開啟 `index.html`。如瀏覽器禁止本機相對腳本，可執行：

```bash
cd stage3r-demo
python -m http.server 8765 --bind 127.0.0.1
```

在本機開啟 `http://127.0.0.1:8765/`；系統只提供合成資料，不會連線司法 API。本輪另有獨立離線預覽 ZIP 可直接解壓使用。

## 六、下一輪應處理什麼？

**先規劃可信官方資料到畫面欄位的安全資料契約（source-to-UI mapping）**，尤其：

1. 法規官方查詢的版本 ID、修正公布日、施行規定、生效範圍、來源查核時間和失敗時降級規則，不得以模型推論填補。
2. 函釋每個 ID 的官方全文／要旨型態、發文機關、發文字號與日期、最後來源核對紀錄；效力狀態由後續明確依據認定，沒有證據時維持待查。
3. 版型可在另一獨立分支加上可信資料契約的模擬 API 和更多實例，但**不可從合成示範直接接入未驗證官方資料或公開裁判功能**。
4. 真正與 `development/v2.7/` 整合及部署，需要另外獨立驗收並取得使用者明確同意；本輪沒有授權修改正式環境。
