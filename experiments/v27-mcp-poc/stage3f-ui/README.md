# v2.7 × MCP｜第 3 階段第六輪：裁判來源狀態展示臺

> **純合成、離線、獨立的 UI 原型，不是真正裁判檢索服務。** 已直接存入 `experiment/v27-mcp-stage3f`，不會部署 v2.7 測試站。

## 使用方法

在 GitHub 分支中下載本目錄的 `index.html`、`model.js`、`app.js`、`style.css` 四個檔案，放在同一資料夾，開啟 `index.html` 即可離線使用。無須安裝套件、申請司法院 API 帳號或配置任何金鑰。

1. 使用主題／狀態選單檢視四筆合成案例（案例 A～D）。
2. 按「模擬點擊並重新查核」，在右側選擇「模擬仍公開」、「模擬已撤除」或「模擬無法回應」。
3. 重複使用同一模擬憑證，確認展示版會拒絕重放。
4. 模擬撤除後，案例狀態與四種統計立即更新；「還原全部示例」可重設。

### 區分的資料狀態

| 介面狀態 | 行為 |
| --- | --- |
| **模擬已核對** | 只提供演練「點擊前再次查證」，不直接提供真實個別連結 |
| **待驗證** | 不顯示個別裁判連結，不認定資料不存在 |
| **模擬已撤除／不公開** | 封鎖個別連結與後續模擬核對 |
| **來源無法查證** | 不顯示個別連結，僅允許使用官方通用查詢入口 |

唯一對外連結為 `https://judgment.judicial.gov.tw/FJUD/`（司法院裁判書系統通用入口）。

## 技術與限制

- 純 HTML/CSS/JavaScript，無前端框架、無外部 API、無後端與持久性儲存，使用 `textContent` 安全呈現。
- `model.js` 是可供 Node.js 載入的同一份合成狀態模型；`model.test.cjs` 設有 34 項單元及安全檢查。
- 本地展示的 60 秒 `DEMO_ONCE_` 憑證只是**介面教學工具，不是密碼學安全、真實驗證或身分識別**，與上一輪 Stage3e 的後端原型並未連接。
- 「模擬已核對」僅是假設狀態，不能作為任何真實裁判仍公開、判決內容正確、歷審完結或撤除合規的證明。
- 真實裁判的獨立官網正文核對、官方 API 授權、真實撤除名單及可信後端安全閘門尚未完成；**第 3 階段整體未通過正式驗收**。
- 本分支只加入 `experiments/` 的測試介面及專用 GitHub Actions；沒有修改 `development/v2.7/`、`services/v2.7-judgment/`、v2.5、main 或 Cloudflare。
