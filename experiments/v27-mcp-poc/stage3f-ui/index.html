正式系統的安全原則

若沒有可信的官方證據，就不能宣稱個別裁判仍公開，也不能憑過往快取認定裁判未撤除。

司法院裁判書系統通用入口 ↗此為唯一對外連結；本原型不提供任何個別裁判深連結。
