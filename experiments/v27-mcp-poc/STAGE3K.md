# v2.7 × MCP｜第 3 階段第十一輪（Stage 3k）：歷審關聯裁判「可回查性」有限抽樣

**分支**：`experiment/v27-mcp-stage3k`（基於第十輪 `experiment/v27-mcp-stage3j`），不修改 `main`、v2.5、`development/v2.7/`、`services/v2.7-judgment/` 或 Cloudflare。

## 已確認的前提，不重做

- 第九輪 10 件真實公開裁判來源、文字忠實性、法院／案號／日期各 **10/10**。
- 第十輪 10 件官方歷審清單與 MCP 清單逐欄核對 **10/10**；其中 **7 件有歷審項目、3 件官方清單為空**，總共 **27 個列示項目**。
- 清單相符不保證整個歷審完整、上級審裁判都公開、裁判已確定或之後不會撤除。

## 第十一輪的可證明範圍

**L3「關聯裁判可回查性」有限抽樣**：只對前輪 7 件有項目的官方歷審清單，每組最多選 2 筆不同、官方端點已提供連結的關聯裁判；整輪最多 14 件，不重做原本 10 件的 MCP 文字比對，也不下載／保存全部 27 件。

| 資料類型 | 次數上限 | 安全規則 |
| --- | ---: | --- |
| 原先 7 件父裁判官網頁面 | 7 GET | 只擷取官方歷審索引 key |
| 官方 `GetJudHistory.ashx` 歷審清單 | 7 GET | 僅官方 HTTPS 網域、固定路徑及對應 key |
| 關聯裁判官方 `data.aspx` | 14 GET | 僅歷審清單列出的合法 JID，重建可信 URL，不沿用任意輸入連結 |
| MCP／司法院需會員授權 API | 0 | 不連線、不取用帳密、Token 或私有資料 |

**抽樣原則**：
- 只讀有實際連結且不是既有 10 件父裁判的關聯項目。沒有連結的歷審項目列為 `listed_without_public_document_url`，不當作無歷審。
- 排除專門少年／家事法院、少年／家事等敏感案號類型，以及不在此次允許清單的法院代碼；不發出未公開少年事件裁判查詢。
- 每組從可檢查的關聯項目選首、末兩個不同識別碼；跨組去重，不重查已驗收的 10 件。
- 官方網頁即使 HTTP 200，仍須具有可辨識的正文區塊、**關聯裁判本身**的法院、年度、字別、號數，以及與該 JID 一致的官方裁判日期，才可標為 `passed`。
- 官網逾時、頁面無正文、案號／日期不符、連結被移除或無法辨識：標為 `review`；不能自行補全或把查不到推論為已撤除。
- 不跟隨轉址、不作大量重試、不繞過網站反自動化機制。
- GitHub 僅保存父裁判預先存在的匿名代號、官方歷審項目數、抽樣數、是否核對成功及錯誤類型；**不保存、列印關聯裁判 JID、原始網址、裁判正文、當事人、案情、附檔或歷審說明文字**。
