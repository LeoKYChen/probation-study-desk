## 不應誤認的限制

1. 「模擬已核對」由純合成資料提供，不是司法院真實 API 或裁判正文核對。
2. 本地前端的模擬 60 秒憑證**非加密安全的正式登入或身分驗證**；前輪 Stage 3e 的獨立後端安全原型未接入此靜態頁面。
3. 沒有真實個案查詢、撤除狀態驗證、官方全文核對、後端身份驗證或點擊時實際向司法院查詢。
4. 只提供通用連結仍涉及使用者自行開啟官網；不能依此推論特定裁判公開、已確定或歷審完整。
5. **未修改** `development/v2.7/`、`services/v2.7-judgment/`、v2.5、Cloudflare 或主分支；本輪僅新增獨立測試原型與 GitHub Actions。
