## 具體測試標準

| 項目 | 此輪驗證 |
| --- | --- |
| 搜尋時禁止個別裁判網址 | 僅回傳48位十六進位亂數憑證及不含個案資訊的提示 |
| 一次性憑證 | 首次點擊即消耗；重複點擊與同時雙重點擊都不會導致再次導向 |
| 有效期限 | 60秒，過期後只能至官方通用入口 |
| 工作階段隔離 | 不同合成工作階段無法互用憑證 |
| 兩階段官方驗證 | 先於搜尋確認，再於點擊發出新的查核；舊驗證不能重用 |
| 撤除安全 | 點擊前、驗證後及返回決定前均需通過撤除確認；任一次異常皆不回傳個別網址 |
| 可信來源 | 官方 HTTPS 網域、指定路徑與 JID 必須一致；HTTP 200 不足以宣稱裁判正文存在 |
| 可用性與防護 | 官方查證失敗、憑證消失、來源錯誤、超時、額度滿時回到通用入口 |
| 個資與資料最小化 | 不輸出第三方的裁判正文、摘要、姓名、案情或不可信連結 |
| 離線測試保護 | 拒絕所有真實案號，只接受 `TEST_JID_SYNTHETIC_...`；不建立網站端點 |

## 不能誤解為正式安全合規的事項

1. **沒有可信的真實官方驗證器。** 所謂重新查證在此只是注入的假函式，回傳的是純合成證明；前幾輪發現司法院官網部分裁判直接讀取不到正文，這個問題尚未解決。
2. **沒有點擊導向的正式 HTTP 服務。** 此輪只產生「導向決策」，並不代表已建立受控後端、驗證使用者真實身分、處理 CSRF／防重放／請求頻率或導向後的撤除變化。
3. **60秒是測試憑證期限，不是裁判公開狀態的持續有效保證。** 憑證即使點擊時驗證成功，之後仍可能被撤除，已離開本站的官方網址也無法被站方收回。
4. **程序記憶體仍暫存合成 JID 與雜湊工作階段。** 未來即使不持有裁判全文，也不能以「無正文」推論完全沒有個資處理；真實服務應審核暫存、日誌、會話、錯誤追蹤及分析工具。
5. **目前的模擬工作階段不是身分認證。** 正式服務需要可信後端的安全會話憑證，而非依賴可由呼叫方自行宣稱的工作階段字串。
6. **外部撤除名單／可信版本見證尚未建置。** 本輪透過合成回傳值模擬，未驗證真實撤除同步、資料庫滾回及備份重現。
7. **未完成十件真實公開裁判原文、日期與歷審的獨立驗收。** 也未取得司法資料開放平台 API 的使用授權。

## 後續安全設計建議

正式網站現階段只適合放置**司法院裁判書系統通用入口**，不得上線個別裁判深連結自動驗證功能。待有合法穩定的官方資料存取管道後，再評估獨立受控後端，在使用者點擊當下查詢官方、查驗撤除／公開狀態、控制暫存與日誌，才逐步開放個別連結。

下一輪可優先做獨立的**點擊流程狀態機及錯誤邊界**、不留個案資訊的介面可用性模擬，或者整理官方來源接入所需的授權／法遵清單；但在來源限制解決前不應把合成測試結果視為第三階段正式驗收通過。
