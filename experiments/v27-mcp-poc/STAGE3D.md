# v2.7 × MCP｜第 3 階段第四輪：官方連結模式（Stage 3d）

**定位：純離線、純合成案件的安全原型。不是可上線的裁判書檢索服務。**

本輪不使用真實裁判、JID、官方帳密或任何網路 API。不修改 v2.5 正式站、v2.7 原有測試站，也不把測試功能放入 Cloudflare Pages。

## 原因與架構選擇

第 3 階段第二輪發現：MCP 可以取得個別公開裁判全文，但另一條直接讀取司法院官方頁面的途徑可能只有 HTTP 200，沒有實際判決正文。**因此目前還無法可靠完成真實裁判正文獨立核對，更不能直接把 MCP 擷取結果當成可公開的完整資料。**

為減少持有裁判全文與撤除風險，先評估只提供**官方來源連結**的產品模式。此模式依然需要處理「原本公開、後來撤除」的風險，而且**只有連結並不自動等於完全合規**，因為 JID、案號、搜索詞、點擊紀錄及伺服器日誌亦可能揭露個案資訊。

## 新增元件

- `stage3d-link-only.cjs`：無任何 HTTP、儲存、資料庫或外部依賴的純合成驗證協調器，只有注入式 `search`／`verifyOfficial`／`isRevoked`／`assertWitness`。
- `stage3d-link-only.test.cjs`：以合成資料測試 URL 官方網域白名單、嚴格案號對應、撤除前後查驗、失效期限、錯誤時封鎖，以及絕不輸出原文或當事人資訊。
- `.github/workflows/test-v27-mcp-stage3d.yml`：Node.js 24 上執行本輪單元測試及既有私有裁判合成回歸測試，並檢查私有元件未進入公開 Pages 資產。

### 最小產品規格（只供未來架構評估）

| 情況 | 本輪對應行為 |
| --- | --- |
| 個別公開裁判，可信的**獨立官方查核**確認 JID、法院、官方正文存在、成人公開案件身分，且查核時間在五分鐘內 | 僅產生司法院官方個別連結，不提供原文、摘要、人物、案情 |
| 來源只有 MCP 快取、官網回 HTTP 200 卻沒有可辨識正文 | 不提供個別連結，改提供官方裁判書系統**通用入口** |
| 裁判撤除／不再公開、查核或撤除資料庫無法取得 | 不提供個別連結；不回傳原始 JID |
| 驗證來源跳轉到非官方網站、附加可疑參數、未經 HTTPS | 不提供個別連結 |
| 已核對的連結超過 5 分鐘，或查核時間在未來 | 不提供個別連結，需要重新查核 |
| 使用者輸入個案卷證內容或非指定練習主題 | 本輪測試直接拒絕；此限制不代表未來產品可以保留個案搜尋紀錄 |

**所有測試 JID 均以 `TEST_JID_SYNTHETIC_` 開頭；任何真實裁判識別碼都被本輪程式拒絕。** 流程只接受「竊盜、詐欺、偽造文書」三項純展示用題目；不具實際裁判檢索能力。

## 不可省略的正式上線前提

1. **後端可信的官網查核**：不能讓前端或第三方 MCP 自行宣稱 `public` 就取得可展示個別連結的資格。實際司法院網站目前部分頁面難以在 GitHub CI 取得正文，這項問題仍未解決。
2. **點擊時再次驗證**：本輪只檢查「產生連結當下」的短時間證明。真實 UI 需在每次開啟個別來源連結前，於可信後端再次檢查是否公開、撤除名單與來源，避免舊畫面保留可點擊的連結；未完成前不可直接對外展示個別連結。
3. **日誌、引用與複本限制**：即使不存正文，搜尋詞、JID、HTTP 存取日誌、CDN 快取或外部分析工具仍可能儲存個資。應確認傳輸、保留時間、日誌關閉及去識別。
4. **來源明確**：若無法確認當下仍公開，只顯示司法院官方**通用查詢入口**，並註明「尚未獨立驗證個別裁判公開狀態」，不得稱查無此案。
5. **不涉及未公開少年裁判**：本輪只接受合成資料；正式產品不應透過檢索迴避少年事件的公開限制。
6. **沒有完整法規法律適用判斷**：即使官網連結可開，也不等於裁判已確定、最新、適用於個案或來源包含完整歷審。

## 驗收界線

- GitHub Actions 成功：只代表合成安全與既有回歸測試通過。
- Stage 3d `synthetic_link_mode_tested=true`；真實裁判來源驗證、實際撤除合規及使用者產品驗收仍為 `false`。
- 不取得帳號、不部署 Worker、不產生持久性裁判索引、不儲存裁判內容。
- 若後續需要公開，須先討論是否直接以官方入口搜尋為主，或建立有合法授權、可確認公開狀態的輕量可信後端。這是**產品／法遵決策**，不是僅靠通過測試便能跳過的步驟。
