# v2.6 版本整合與部署｜隔離開發

狀態：規格基線（非上線版本）。

## 目標
整合國考作答系統、每日30分鐘學習臺與 v2.7 法源檢索服務，確保資料及部署穩定。

## 必要工作
- 梳理 v2.5 GitHub 正式版、Cloudflare v2.5.2a 手動部署版之程式差異。
- 統一資料結構，題目使用穩定ID，保存資料版本。
- 不以不同網域之 localStorage 互通作為假設；先以匯出／匯入完成跨網域遷移。
- 明定各模組接口、單元測試、回滾及部署流程。
- 部署前保留備份，且不得動到 main 與現行 Cloudflare 測試站。

## 驗收
可回滾、跨版本資料匯入成功、無破壞性改動、正式資料與測試資料分離。
