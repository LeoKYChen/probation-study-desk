# v2.5.3 國考申論強化｜隔離開發

狀態：規格基線（非上線版本）。

## 目標
每日30分鐘的申論練習，包含5分鐘審題、20分鐘作答、5分鐘自評；提供10分鐘模式。分科支援法律科目之爭點／法律依據／涵攝／結論，以及學理科目之概念／理論／比較／應用。

## 開發規則
- 不修改 main 正式站。
- 不以尚待校正的342題作為正式題庫。
- 必須先取得並核對 Cloudflare v2.5.2a 最新版程式，再實作相容性遷移。
- 每日30分鐘原有 localStorage 資料不得覆寫；先備份，並驗收舊紀錄可讀。
- 自評分數不宣稱是考選部成績。

## 驗收
手機草稿保留、重新開啟還原、各科不同答題模板、間隔複習相容、資料匯出匯入均測試通過。
