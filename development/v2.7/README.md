# v2.7 臺灣法律AI：共用檢索引擎與雙模式（2026-10-15）

測試站：https://probation-legal-ai-test.pages.dev/

## 當前已完成：v2.7.0 第二階段法規快照
- 國考學習／專業研究雙模式共用同一筆條文文字及官方連結。
- 《少年事件處理法》（C0010011）120條文紀錄、《保安處分執行法》（I0030002）103條文紀錄，合計223條文紀錄。
- 法條資料存放 `development/v2.7/laws.json`，來源為法務部全國法規資料庫中文法律開放資料API（`https://law.moj.gov.tw/api/ch/law/json`）。
- 官方資料更新標示：`2026/10/2 上午 12:00:00`，只代表來源資料版本，不代表所有條文於該日施行。
- 瀏覽器搜尋法名、條號及條文；每次最多顯示25筆，可逐批增加；資料取得失敗時會顯示6條示範資料，明確提醒範圍限制。
- 網頁是純檢索工具，**沒有**啟用模型生成、歷史法適用比較、函釋或裁判查詢、雲端私人研究紀錄。

## 維護流程
1. `development/v2.7/scripts/sync_official_laws.py` 下載官方壓縮資料，僅匯出指定兩部現行法律。
2. 解析器對法規代碼、數量、條號重複、必要條文作失敗即停止（fail-closed）的檢查。
3. `scripts/test_sync_official_laws.py` 使用**合成測試資料（不發布）**進行5項單元測試。
4. GitHub Actions `.github/workflows/sync-v27-official-laws.yml` 執行來源下載、檢查、更新 `laws.json`、Cloudflare Pages 部署；若下載或核對失敗，不覆寫原資料。
5. `.github/workflows/deploy-v27-cloudflare.yml` 負責日常前端變更的部署，包含JavaScript語法及資料格式檢查。

**重要排程限制：** GitHub 的 `schedule` 事件只會在預設分支執行。目前同步工作流程僅存在 `feature/v2.7-legal-search`，因此雖寫有每月1日與15日的排程設定，**尚未形成可靠的自動定期更新**。現階段可透過該分支相關檔案提交，或至 GitHub Actions 手動觸發 `workflow_dispatch`；欲啟用真正無人值守的定期同步，需另外設置預設分支專用排程工作流程（此項尚未辦理）。

## 法律研究安全規則
- 資料為現行法快照；不得拿它直接判斷過往案件的行為時法或條文個別施行日。
- 檢索無結果只代表目前的兩部法律中沒有匹配內容，不代表臺灣法律不存在該規定。
- 公開資料與非公開少年案件及個人卷證資料分離；不得上傳非公開案件、私人學習紀錄、密鑰。
- 官方條文請回查來源連結；條文內容與資料庫生效日不同步時以官方公布適用資訊為準。
- 此站不提供官方國考評分或正式法律意見。

## 手動驗收
- 開啟測試站，看見約223筆收錄、兩部指定法律及官方快照日期。
- 搜尋 `第3條之1`，應找到完整包含「通譯」的少年事件處理法條文。
- 搜尋 `保護管束`；切換兩種模式，來源條文不應改變。
- 切換法規篩選；測試沒有結果的關鍵字，須顯示範圍限制。
- 手機進行橫向/直向版面及大量結果分頁測試；通過後才視為使用者驗收完成。
