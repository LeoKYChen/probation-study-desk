# v2.7 臺灣法律AI：共用檢索引擎＋雙模式

狀態：v2.7.0-alpha；先做法條來源核對及最小檢索原型，不部署AI問答。

## 模式
- 國考學習：以法條與考點為起點，提供可核對來源；暫不做自動評分。
- 專業研究：顯示法規類別、來源、最後來源核對日期與研究限制。

## 資料與風險
- 初始資料僅收錄人工核對的法條範例，不宣稱全法規收錄或即時同步。
- 官方來源：少年事件處理法 C0010011、保安處分執行法 I0030002。
- 現行法與歷史法、法規與函釋、公開裁判與非公開少年裁判必須嚴格區分。
- 不收集或公開真實非公開少年案件、機敏卷證、個人資料。
- 後續導入自動更新、函釋與公開裁判時須另訂資料取得權限、更新撤除程序與可重現測試。

## 驗收
可在手機與桌面操作；條號與關鍵字可搜尋已收錄資料；每個結果連到官方來源；有範圍限制及無結果警示。

## 測試
開啟 `development/v2.7/index.html`；在國考及研究模式搜尋 `第3-1條`、`保護管束`；確認結果和官方法條、來源連結，切換模式不改變法源資料。此為離線靜態介面，尚無正式資料同步或大模型。
