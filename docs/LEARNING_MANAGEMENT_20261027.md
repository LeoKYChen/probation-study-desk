# 學習管理（2026-10-27）

依使用者確認之四項需求修改原 lectures 模組：導覽改名、取消90天限制、月曆編輯與逐項完成，以及採用提供圖片的進度總覽、各科進度、接續堂次、期限與筆記配置。

## 操作

- 保留既有課程，可補充教師與觀看期限。
- 輸入預排天數或結束日期，預覽後確認；支援跨年度。長期排程省略已無待排工作的空白尾端，月曆仍可切換日期。
- 點選月曆日期新增函授、閱讀、複習或申論項目；逐項修改日期、內容、預計分鐘、完成狀態、完成進度、實際分鐘及重點疑問。
- 函授完成進度同步對應堂次；閱讀等項目不增加函授分鐘。標記完成不會自行填入實際學習時間。
- 已編輯的項目保留日期並占用當日時間；重新自動排程只分配其他尚未安排的函授分鐘。需要移動已編輯項目時，在該項目的日期欄調整。
- 有紀錄的項目保留，避免誤刪；如要移除，先在編輯中清空其進度、實際分鐘、筆記與複習標記。

## 資料與驗證

沿用 psd-lecture-planner-v1，schema仍為1，以可選 activities、teacher、expiresOn 欄位擴充。舊紀錄無須手動搬移。完整JSON備份支援紀錄匯入與衝突保留；函授分鐘有衝突時，相關新活動先存衝突版本，避免默默採納不一致的完成紀錄。不同來源與裝置不自動同步。
