## 本版主要功能

- **備考書桌**：依學習範圍選題、保存多次作答、四格申論、人工及 AI 評語、訂正、再次回想、使用者確認的弱點與 Markdown 筆記。
- **專業與共同科目**：保留歷屆試題、30 分鐘練習、國文作文、英文、主動回憶、函授課程進度與 7／30／60／90 天規劃。
- **每日模擬題／晚間學習室**與**少年司法週報**：延續既有閱讀、練習及來源標註流程。
- **雙 AI 協作交接**：在支援的頁面由使用者確認送交外部工作臺，完成後由使用者決定是否回填，避免直接覆蓋原答案。外部服務 API 金鑰與費用由使用者自行管理。
- **備份、列印及離線**：保留 JSON 手動匯出／匯入、瀏覽器 PDF 列印及 HTTPS PWA／離線功能（各模組支援範圍不同）。
- **警察特考歷屆原題**：新增 108–115 年指定四科、32 份官方原卷的 127 題 AI 輔助官方 PDF 比對資料；原有 426 題 ID 不變。v2.5 考古題練習臺及備考書桌可載入 **553 題**；`professional/` 仍為原有 426 題。

## 穩定維護與相容性

- 既有凍結基準分支 `archive/stability-baseline-20261023` 保留供原始碼回溯，不能取代個人資料備份。

1. **警察原題 32 份試卷尚待真人逐卷逐字校稿**（9 卷／31 題優先覆核）。已進行的官方 PDF 來源比對屬 AI／程式輔助，不代表全部人工核稿、法律正確性或官方標準答案驗證。見 [人工核稿清單](https://github.com/LeoKYChen/probation-study-desk/blob/main/police-exams/reviews/OFFICIAL_32_PAPER_CHECKLIST.md)。

4. 跨裝置雲端同步暫緩。請在更新前使用網站的備份中心或各模組匯出 JSON；不同網域與裝置的資料不會自動同步。
