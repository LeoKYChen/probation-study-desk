# 第四階段：離線閱讀、離線作答與保留紀錄（獨立測試版）

此工作**不涉及**第五階段 ZIP 離線版，也不合併至正式網站。使用既有 HTTPS PWA、root service worker 和原先各練習區的 `localStorage`；**不建立第二套答案儲存機制**。

## 已有功能（開始前盤點）

- `sw.js` 可下載原子性資源快照，使用 Cache Storage 儲存網頁、題庫與樣式。更新失敗時不應取代上一個完整快照。
- `offline.js` 原有安裝與快取控制，但是**既有下載清單缺少很多新頁面**，首頁也沒有統一下載入口。
- `professional/sw.js` 已有自己更小範圍的獨立 Service Worker；本階段不更動該檔，避免覆蓋或清除已安裝的舊版快取。
- v2.5、每日模擬、v2.5.4、國文作文已有各自持久化作答儲存；離線後繼續沿用原鍵，不能隨意覆寫。

## 本次修改

- 將 `offline-manifest.json` 由原 75 個擴充至 **195 個**資源（原有資源完整保留），納入專業科目、426題、125題每日模擬、共同科目、少年司法週報、JSON 備份及列印中心。
- 在首頁側邊欄加入「離線閱讀與作答」，保留五個學習主入口。
- 新增 `offline/index.html` 操作頁；沿用 `offline.js` 的既有下載／更新、進度、狀態、安裝主畫面按鈕。
- 根目錄 Service Worker **維持原版檔案位元組不變**，原有的原子完整快照、下載失敗保留上一份快取和必要頁面的線上優先規則均保留。新增頁面於離線狀態從完整下載的快取取用；恢復連線後應主動按「更新離線資料」。
- 修正原對話框「342 題專題」等不符合目前階段範圍的舊文案。

## 正確使用

1. 手機或電腦連線使用同一個網站網址，開啟「離線閱讀與作答」。
2. 按「離線使用」→「下載離線資料」，等候全部檔案下載完成。
3. 開啟飛航模式，再從相同網址進入練習頁，開一題並試著輸入文字。
4. 關閉頁面、重開，確認原文字仍在本裝置；恢復連線後使用第二階段「完整 JSON 備份」另存學習紀錄。
5. 需要新題目時先連線，再次下載新離線快取。

## 注意

- 離線內容限**先前已完整下載的版本**；少年司法週報與法規資料可能過時。
- 此版本的 PDF 列印中心可離線開啟，但作業系統列印／PDF 功能由使用者的瀏覽器支援決定。
- 練習 AI 模型、外部法律與網站連結、Google Drive 手動傳檔仍需網路。
- GitHub Pages 和 Cloudflare 網址必須各自準備快取，彼此的本機答案不共用。
- 個人答案在 `localStorage` 而非「題庫快取」裡；Safari 自動清理、儲存不足或刪除網站資料都可能清掉。務必定期下載 JSON。
- 舊版專業科目的 Service Worker 是另一個獨立安裝範圍；真實 Safari 主畫面 App 的離線行為仍需本人驗收，不把模擬器結果冒充 iPhone 真機成功。

## 驗收

- `node verification/offline-stage4-check.cjs`：完整列表、確切檔案路徑、JSON、HTML 依賴、原子快照機制及五入口保留。
- `verification/offline-stage4-browser.cjs`：實際 Chromium/WebKit 模擬手機「下載 → 飛航模式 → 考古題／國文作文作答 → 重新開頁答案存在 → 每日模擬／專業科目／少年週報／備份／列印中心離線可開」。
- Cloudflare 只部署 `stage4-offline-preview` **獨立分支**，並驗證其內容與該分支 HEAD 逐檔一致。正式部署必須另經使用者確認。
