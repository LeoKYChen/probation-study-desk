## 本輪修正與語意

- 原版 `age > 7` 在滿七天時尚未提醒；本預覽定義為經過 **7 個完整日**即提醒（`>= 7`），待使用者確認是否接受此提醒時點。
- 原版延後為布林旗標，無明確期限；改為延至下一個模擬日，不更新已確認備份日。
- 兩個範圍分別保存合成的確認日及延後期限；按下載不代表已保存。只有「我已確認保存」重設該範圍的提醒時計。
- 增加「從未備份」示範，立即提醒；空值、負數、小數及超過 365 天顯示錯誤且不改變目前狀態。
- 時鐘向前保留各範圍狀態，向後重設兩範圍至第 0 天已備份的合成情境；這是示範操作，不是正式日期回撥處理方案。
