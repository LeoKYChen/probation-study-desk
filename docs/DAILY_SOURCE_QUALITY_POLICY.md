# 每日模擬題來源品質與學習可用性規格（草案）

版本：2026-11-08；僅供獨立開發分支測試，不代表正式上線。

## 一、分類狀態與內容品質不得混同

- **可練習**：有可獨立作答的完整題幹，且可辨識科目。可閱讀、作答、儲存與搜尋。
- **待分類**：有可獨立作答的完整題幹，但科目缺少或不明確。仍可閱讀、作答、儲存與搜尋；列在「待分類」篩選，不計入單一正式科目統計。
- **待補正**：缺少完整題幹、僅指向本文其他段落，或無法單獨理解。不得冒充可作答題目；先保留來源與錯誤理由供人工修復。
- **非題目來源**：須確認文件實際沒有考試題目，才可由人工或可信規則判定，不能因解析失敗直接推定。
- **解析失敗**：讀取／解析程序錯誤，需保留診斷；不代表文件內容一定不完整。
- **內容待核對**：法律依據、官方出處或新聞真實性尚未審核，與上述狀態獨立。

## 二、保護既有 245 題

- 不自動改寫已發布題號、題幹、日期、科目及使用者作答資料。
- 對現有待分類題目不應為了改分類直接重建題號；此項仍需另行設計受控的分類覆寫機制，完成前不自動批次重分類。
- 不得把「待分類」轉成「待補正」：只有題幹不完整才應暫停練習。
- 自動來源健檢不構成發布授權；所有候選新題須另行校驗。

## 三、格式規格

新版來源應包含日期、明確的考試專區、科目欄、可獨立作答題目。不同舊版 Markdown 格式可容許，但不能以檔名或星期幾推測科目。各來源的品質標記應由實際解析結果決定，而非單憑檔名新舊推斷。
