## 四、測試邊界

1. **不同網址不共享瀏覽器紀錄。** `v254-preview`、`v254-content-preview`、`v254-unified-preview` 分屬不同來源；如需帶入資料，使用每日30分鐘模組自己的 JSON 匯出／匯入（建議先保留原始檔，不要直接完整覆蓋）。
2. **此站備份仍是每日30分鐘模組獨立的 JSON**，尚未與 `/v2.5/` 考古題練習站合併成跨站單一備份；原有匯出檔名亦未統一改為民國日期。
3. 外站頁面可能要求登入；連結校對狀態已在畫面區分，第三方討論與擬答非官方標準答案；不會自動傳送作答與評語給外站。
4. AI評分須把批改提示詞自行貼入ChatGPT，然後原文貼回；沒有使用付費API、沒有網站自行評分。
5. 目前已通過 Chromium 390px 行動版視窗測試；**未在實際 iPhone Safari 完成真人驗收**。
