# v2.5.4 第一階段：七科學習能力分析與弱點追蹤

## 範圍與版本隔離

- 來源只使用原站 426 題：`v2.5/questions.js` 374 題＋`v2.5/related-questions.js` 52 題，皆由既有 Stage 6 打包機制取得。
- 342 題預測題庫與題庫分批匯入不屬於本階段。
- 開發分支 `feature/study30-v254-analytics`，從 `release/v2.5.3-study30-stable` 建立。
- 部署目標為 Cloudflare Pages 的 `v254-preview` **預覽分支**。不得將預覽版部署到 Pages `main`，也不得修改 GitHub 正式版 `main`。
- 本階段新增的 `v254-diagnostics.js` 僅讀取 `Study30App.getEssayReviewData()` 與既有 Review / EssayAnalytics 計算結果，不新增儲存鍵或改寫資料。

## 統計規則

1. **每日自評**：三段評級「需要再複習／還不完整／能自行說明」，僅計入題庫中確有題號的歷屆題。無題號、無自評及未來日期不納入。
2. **申論自評**：只使用既有 `Study30EssayAnalytics.collect()` 提供的完整自評紀錄。分數是個人自評，不是國考實際得分，兩套自評不可相加。
3. **同題跨日**：只比較同一題、不同日期的連續評量；每日自評按三段等級進退，申論按同題分數增減統計。
4. **反覆弱點**：同科相同原因需於所選期間內至少兩個不同日期出現才標記；同日重複標記只算一天。
5. **科目**：七科分開顯示。刑事訴訟法與保安處分執行法共用歷屆題可列入兩科視角，但全站紀錄總數不重複計算。
6. **到期待複習**：依 v2.5.3 原有複習規則判定，顯示截至今日仍到期的原題，不擅自重新排程。
7. **優先建議**：根據到期數、同題反覆未掌握及反覆弱點排序。無紀錄就顯示資料不足，不給沒有根據的能力評分。
8. **期間篩選**：7／30／90天及全部紀錄；到期狀態代表「目前仍到期」，不隨期間選項隱藏既有債務。
