# 觀護人兩版試評

原有版本保留現有全科426題規則。補充版本涵蓋108至115年觀護人六科190題，其中54題沿用原已完成規則，136題新增逐題參考綱要、來源支持範圍及四項理由。110年諮商與輔導及115年刑法原卷各只有三大題，因此不是192題。完整原題未修改。

答案、草稿與完成狀態共用；兩版試評、人工調分及逐點回饋分別保存。舊紀錄預設歸原有版本，切換不自動重評。舊答案的結果保留，答案修改後提示重新試評。平均線索分僅計算所選版本；備份與同步保留版本快照。

136題均有定向來源查證記錄，不代表全文每項主張均已證實。法律題區分現行有效法、行為時法及未施行修法；資料不足及合理異說逐題列明。尚未經獨立專業人工審閱或專家答案集校準。數字只代表辨識的論述線索，並非正確率或國考分數。計算、任選、數量、方案及否定語句等需要覆核時，不給總分。

## 驗證

執行 `node verification/trial-versions.test.cjs`。涵蓋190題範圍、原426題規則與原題未變、136題來源及四項理由、544個空白／抄題／關鍵字案例、版本切換、人工調分與回饋、答案修改、備份／合併及計算題覆核。

另以瀏覽器驗證原版試評、切至補充版、重新試評、切回原版及重新載入，確認答案及兩版結果保留；小螢幕比較內容上下排列。

## 入口與復原

`v2.5/index.html` 題目下方可選版本，並展開兩版要點及來源。`v2.5/probation-trial-review.html` 可篩選190題及試用同答雙版試評，不寫入正式練習紀錄。

可還原本次程式修改；還原程式不會刪除使用者資料。較舊程式只認得當時選中版本的頂層結果，應保留包含版本快照的完整新版備份。
