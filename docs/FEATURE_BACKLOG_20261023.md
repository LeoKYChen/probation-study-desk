## 5. 維護順序與完成證據

本節只列**凍結決策允許的管理順序**，並不批准新功能：

1. **來源與題庫品質**：官方警察題庫 32 卷真人核稿、題目原文與配分、每日題與法律時點勘誤。
2. **現有系統安全與資料完整**：Apps Script 更新防回滾、JSON 匯入匯出、題目 ID／答案版本相容、必要的 Safari 問題修復。
3. **既有內容更新**：少年司法週報來源核對與新增期別，維持 JSON 主檔及鏡像一致。
4. **發布前驗收**：針對具體 main SHA 分開記錄 CI、GitHub Pages、Cloudflare、實機 iPhone、正式 Release／還原點；不得將 skipped／cancelled 當 success。
5. **封存與獨立化管理**：只保留已核定的歷史 SHA、權限及遷移驗收，不因本清單而擴充 H／J／M／N。

### 驗收證據欄位（未來追蹤使用）

對任何擬更新的功能，至少記錄：`ID`、`決策依據`、`PR/commit`、`程式測試`、`內容人工核查`、`正式站實測`、`資料相容`、`已知限制`。不要把「文件已記錄」「程式已合併」「人工校稿」「已部署」混為單一完成狀態。
