第五階段：觀護人學習平台「雙擊即可使用」完全離線測試版
====================================================

使用方式
--------
1. 下載 ZIP，解壓縮到自己的資料夾（例如「觀護人離線練習」）。
2. 雙擊其中的 index.html，以 Safari 或 Chrome 開啟。
3. 不需要 Wi-Fi、行動網路、localhost、本機伺服器、Colab 或其他安裝步驟。
4. 選擇 426 題考古題、125 題每日模擬、132 題國文作文或歷史少年司法週報。
5. 輸入四格申論、完整答案及訂正筆記；練習完務必按「下載練習紀錄 JSON」保存。
6. 換電腦或換瀏覽器時先下載 JSON，再使用「匯入此離線版 JSON」安全合併。

重要限制：請務必閱讀
----------------
- file:// 下的 localStorage 行為由瀏覽器決定，不保證永久保存，可能隨瀏覽器更新、移動檔案位置或清除資料而消失。網站會偵測無法使用 localStorage 的情況；即使顯示已保存，仍建議每次作答後手動下載 JSON。
- 此測試版的 HTML 及題庫全內嵌，無需 fetch()，只會將答案存在目前頁面的記憶體／可用的本機儲存區；沒有背景上傳，也不會把你的答案傳給伺服器。
- 「匯入此離線版 JSON」僅接受本離線版下載的 JSON；正式 GitHub／Cloudflare 網站的第二階段完整備份是不同格式，**目前不能直接匯入**。請分開保管；後續將評估完整相容的安全匯入轉換。
- 如同一題有兩份不同版本，匯入時會保留目前版本，將新版本留在匯出 JSON 的 conflicts 欄位；不會任意覆蓋。
- 資料截至 ZIP 建置時的專案版本，不會自動更新官方法律或新聞。遇法律適用問題請另至全國法規資料庫查證。
- 此版目前是可雙擊使用的「練習核心」測試版：題庫、四格答案、訂正、歷史週報、離線備份及列印。尚未等同完整正式網站；舊版每日計時細節、個別分析圖表、原英文學習子網站、其他互動小工具及雲端 AI 功能尚未全部移植。
- 檔案放在自己的電腦即可；不用上傳 Google Drive 才能讀題。若要備份 JSON，可自行保存在私人雲端。
- 不要在真實少年事件個案資料中記錄可識別個資或公務機密。
