# 第三階段：申論與作文 A4 列印／PDF 匯出（獨立測試版本）

此功能**不會將個人答案傳至伺服器**、不使用外部 PDF API、不修改原始 `localStorage`、不建立重複筆記資料庫。本階段僅利用瀏覽器原生「列印／儲存 PDF」功能，產生整潔的 A4 黑白文件。

## 可列印的既有紀錄

1. **專業科目 v2.5.4**：原 426 題題幹／手動輸入題目（如原本有存）、當日四格草稿、完整作答、已保存的 AI 回饋、自評與下一次改善目標。
2. **426 題考古題練習臺**：原有題幹、四格草稿、原始完整答案、保存的本站非官方練習評估及逐點筆記。
3. **每日模擬題（125 題）**：原題、四格草稿、完整作答、已貼上的 AI 評語。
4. **國文作文（12 題原創＋120 題改編）**：題目、目前作文、已明確保存的各次修訂版本、回饋及改進目標。

沒有保存內容的區塊不會列印。列印時可決定是否加入評語、自評、修訂版本；單次最多選擇 30 題，可分批列印。

## 使用方式

從網站首頁側邊欄「申論列印／PDF」，或各練習區的列印連結開啟 `print/`。先確認其他分頁的練習內容確實儲存，於列印中心選取題目，再按「產生紙本預覽」及「列印／儲存 PDF」。選擇 A4；電腦在瀏覽器列印視窗選擇「另存為 PDF」。不需安裝第三方套件或上傳答案。

## 已知限制和保護措施

- **同網域限制**：GitHub Pages、Cloudflare 雖使用相同程式，兩個網址的瀏覽器資料仍然分開；使用者須於實際保存答案的網址列印，或先在第二階段的備份中心安全移轉。
- **只列印已儲存的資料**：另開列印頁面時不會取得尚在編輯框裡、尚未成功保存的文字。遇原題不在目前題庫時，明確顯示「尚待核對」，絕不以模型產生的題幹替代原題。
- **AI 評分、自評非正式閱卷**：列印標題與頁尾明示性質；法律、實務內容由使用者事前核對，本功能不增寫擬答或法規解釋。
- **PDF 為瀏覽器另存**：不宣稱直接產生具固定 PDF 相容性的下載檔或保證 iOS 各版列印對話框完全一致。真實 iPhone、Mac 實機操作仍需個別確認。
- **不含第 4、5 階段離線功能**：若每日模擬題 JSON 當下無法讀取，僅嘗試沿用之前快取；絕不自行生成或冒用缺失原題。
- **個資及公務保密**：請勿把機密個案或可識別少年個資放入公開練習網站或隨意分享 PDF。

## 驗收標準

- `node print/test.cjs`：四類既有紀錄、題幹、答案、草稿、AI 回饋、修訂內容、資料毀損和舊版題目兼容測試；不得寫入本機紀錄。
- `node print/test-browser.cjs`：在 Chromium 手機寬度測試多題勾選、預覽、選項切換、列印按鈕、原生 PDF 產生、A4 CSS 列印媒體、原資料鍵維持完整。
- GitHub Actions 只能部署獨立測試站 `stage3-a4-print-preview.probation-study30-test.pages.dev`，**正式主線仍需使用者核准後另行合併**；原先五個學習入口、426 題、每日模擬題資料及 v2.7 停止開發決定均不受影響。
