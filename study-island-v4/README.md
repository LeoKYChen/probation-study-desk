# 觀護學習島 v4｜可探索遊戲測試版

**已部署測試版：** https://probation-study-island-v4-preview-bcobamjgj-ris001214-3112.vercel.app/ （獨立 Vercel 網站；首頁、CSS 與 JavaScript 均已 HTTP 200；尚待 iPhone／Android 實機驗收）。

**獨立開發預覽，未合併正式站。** 依 2026-10-31 的 v4 玩法規格製作。人物、場景及對話為原創內容，不使用任天堂受保護的素材。

## 本機啟動與遊玩

在儲存庫根目錄執行：

~~~bash
python3 -m http.server 8781
~~~

瀏覽 http://localhost:8781/study-island-v4/ 。

1. 點草地移動角色；手機也可用畫面方向鍵，電腦可用 WASD／方向鍵。
2. 點橘色狐狸栗子，角色走到附近後對話。
3. 點貝殼、木材、葉子、果實，角色靠近就會拾取。
4. 打開背包；開局有 1 張免費木椅，按「擺放」後點空地。
5. 在森林小工坊製作木椅、花圃、燈籠；點已擺放家具可收回。
6. 委託可領取遊戲獎勵；學習獎勵每天可自行回報閱讀、申論、訂正或進行 5／25 分鐘計時。
7. 在設定可變更島名、衣服顏色並匯出／匯入 JSON。

## 工程與資料隔離

- 20×16 地圖，Canvas 呈現，跟隨鏡頭、BFS 格子尋路、房屋／樹木／居民障礙、簡單走路動畫。
- 4 名原創居民，各有鼓勵性的對話；12 個採集點每日補充，同一日期不因重整重複獲得。
- 獨立 IndexedDB：probation-study-island-v4，存檔內以單筆交易處理材料扣除、家具製作及獎勵去重。
- BroadcastChannel 僅通知同網域分頁讀取最新存檔；不同裝置／網域／瀏覽器不會自動同步。
- 不讀寫既有考古題、備考書桌或學習管理的 IndexedDB、localStorage、題目 ID。
- 匯入 v3 備份需手動選擇檔案並確認。原 36 格舊家具保留於「舊島花園」展示，v3 原始檔不更動。
- v3 舊家具庫存、成長值與親密度可保存在來源欄位，但尚未轉成 v4 的即時遊玩能力。
- 學習任務為使用者自行確認；不依 AI 分數判定學習完成。
- 不需要帳號、信用卡、雲端後端或外部 API。
