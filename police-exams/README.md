# 108–115年警察犯罪防治預防組｜官方歷屆原題收錄

## 需求與既有平臺相容

**限定108–115年，且只納入下列四份官方科目（按年度逐一查核是否設科）**：

- 一般警察人員考試三等犯罪防治人員預防組：心理學
- 同上：諮商與輔導
- 同上：刑法與刑事訴訟法
- 警察人員考試三等犯罪防治人員預防組：犯罪學與犯罪預防

注意「警察人員考試」及「一般警察人員考試」不是同一考試。其他科目**不加入**。

## 目前實作（不誇大收錄）

- `catalog.json` 保存8個年度與4科32個查核格，以及108–115年已定位且完成來源查核的32份官方試卷URL。
- `tools/collect_originals.py` 從考選部目錄定位試卷，下載官方PDF，由原PDF文字層擷取候選題幹、子題和配分，逐卷檢查年份、等別、類科、科目。不能定位、文字異常或 PDF 不是考選部來源，都在 `audit.json` 保留問題，不以其他來源頂替。
- GitHub Actions `Police original past papers audit (108-115)` 在獨立工作環境產出 `candidates.json` 和 `audit.json` 作為審稿附件；**不發布、也不自動寫入正式題庫**。
- 擷取文字需對照官方 PDF 逐題核對（包括附件圖表、子題與配分），115年16題已進行官方PDF影像、文字層及雙SHA256比對，使用 `tools/promote_reviewed.py` 搭配個別核對收據；核對者明示為AI，**不是人工閱卷**。108–114年另以 `tools/promote_clean_single_page.py` 嚴格比對同一份官方PDF原文、題號、雙SHA256並排除圖片、私用字元與跨頁風險，共新增80道。114年刑法與刑事訴訟法例外是官方三題（50/25/25）且跨兩頁，已由 `tools/promote_114_three_questions.py` 逐頁來源核對後再新增3題。未核對或異常題目不發布。
- `approved-loader.js` 只接受 official-original、已核對、年度與考科合法、具雙雜湊的題目；拒收改編、來源不明與重複ID。現有426題不被覆蓋。
- `v2.5/` 追加批准原題，可使用**刷題王／阿摩（未核對直達頁先提供搜尋）、四格草稿、完整申論、系統初評、一鍵複製AI批改、評語保存、複習與備份**；`study-desk/` 可使用同一份核准原題並保留舊紀錄。
- 既有`professional/` 受版型與來源保護，未修改其原有題庫；完整功能請走 `v2.5/`。

## 如何執行收集（GitHub Actions）

開啟 Actions -> **Police original past papers audit (108-115)** -> Run workflow。預設8年；可填單一年份。

取得附件 `candidates.json` 與 `audit.json`，逐題開啟考選部官方原卷，比對PDF視覺畫面、文字、題號及配分。若PDF為影像檔、公式或圖表無法擷取，標記「待處理」，不虛構文字。若目錄找不到該卷，保留`unresolved`，不得直接當作「當年沒出題」。

核對收據範例（不得在未檢查原卷前填 true）：

```json
{
  "police-115-counseling-1": {
    "reviewedAgainstOfficialPdf": true,
    "reviewer": "人工核對者代號",
    "checkedAt": "2026-10-22",
    "pdfSha256": "從audit和candidate抄錄64位SHA256",
    "textSha256": "該題候選原文SHA256"
  }
}
```

將已核對的收據儲存為JSON後，執行：

```bash
python police-exams/tools/promote_reviewed.py --candidates candidates.json --receipts receipts.json --out police-exams/questions.approved.js
```

新題務必與原來的題庫資料分開保存；確認CI與瀏覽器測試後才提交合併。**未完成核對的題目，既不能進正式網站，也不能加計已收錄題數。**

## LawPlayer 次級題源交叉檢索（2026-10-23）

已研究使用者提供的 [法律人 LawPlayer 犯罪防治人員考古題](https://lawplayer.com/exam/crime-prevention#system)，並於 [`lawplayer-crosscheck.json`](./lawplayer-crosscheck.json) 將**原先28道待核對題目對應至9個年度科目來源頁**（其中114年刑法與刑訴已另行核實完成）。已找到8個年度科目的獨立網頁，108年心理學暫以已核實的跨考試科目索引定位，未假設未確認的獨立頁網址存在。

重要發現：

- 110年心理學：網頁將官方4大題合併顯示為1題。不能依網頁顯示「1題」就覆寫官方原題數。
- 112及113年刑法與刑事訴訟法：網頁也出現多道原題被合併，且內文夾帶官方PDF頁碼。
- 114年刑法與刑事訴訟法：官方確為**3大題，分別50、25、25分**。已檢查原卷兩頁及題號，**3題全部恢復為原題、無須拆題**；原「四題」通用假設已對此卷排除。
- 109年諮商與輔導、111年心理學：網頁可輔助定位特殊子題字元，但真正字形、配分仍需回考選部原卷視覺核對。
- 110年刑法與刑事訴訟法、114年諮商與輔導：可藉網頁的分題來尋找官方PDF跨頁邊界，但不得直接拷貝整理後的網站題幹。

LawPlayer **只作為找卷與辨識抽取缺陷的參考，不作為正式題庫直接來源**。既有127道已核對原題不更動；原先28道疑義已逐題比對考選部官方PDF修復，直到PDF逐字、附圖、子題及配分全數比對完成。
