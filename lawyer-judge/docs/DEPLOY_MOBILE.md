# 手機使用與部署

zip 檔只能在電腦上直接開啟；手機需要一個網址。以下做法免費、不需要 Git。

## 為什麼手機不能直接開 zip

- iPhone 無法從「檔案」App 以完整功能開啟本機網頁。
- Android 的 Chrome 會阻擋本機網頁讀取資料檔，題庫與備考書桌都無法運作。
- 備考書桌使用 ES modules，本來就不能用 `file://` 開啟。

## 用 Cloudflare Pages 上傳（建議）

1. 在電腦上解壓縮 `lawyer-judge-study-desk.zip`。先匯入題目（見[題庫匯入指南](QUESTION_IMPORT.md)），再把整個資料夾重新壓成 zip。
2. 登入 Cloudflare，進入 **Workers & Pages → 建立 → Pages → 直接上傳**，取一個專案名稱，把 zip 拖進去。
   - 拖放上傳限制：最多 1,000 個檔案、單檔 25 MiB。本專案約 340 個檔案，最大的檔案約 15 MB。
3. 完成後會得到 `https://<專案名稱>.pages.dev`。

這個網址和觀護人站（`leokychen.github.io`）不同網域，兩站的瀏覽器紀錄不會互相干擾（見[決策 D7](DECISIONS.md)）。

## 手機上設定

1. 用 Safari（iPhone）或 Chrome（Android）打開上面的網址。
2. 加到主畫面：
   - **iPhone**：分享 → 加入主畫面。
   - **Android**：右上選單 → 加到主畫面（或「安裝應用程式」）。
3. 從首頁側欄的「離線閱讀與作答」下載離線資料，等到顯示「已備妥」。之後沒有網路也能看題、作答。

## 之後要注意

- **更新題庫**：在電腦匯入新題目 → 重新壓縮 → 在 Cloudflare 同一個專案上傳新版本。手機重新整理（或重新下載離線資料）即可。
- **紀錄不會自動同步**：手機和電腦的作答各自保存在各自的瀏覽器。要搬移時，在「學習紀錄備份」匯出 JSON，到另一台裝置匯入。
- **定期備份**：清除瀏覽器資料、使用無痕模式或更換瀏覽器，都可能讓本機紀錄消失。

## 驗收清單（部署後在手機上跑一次）

- [ ] 首頁、專業科目、考古題練習臺、備考書桌都能開啟
- [ ] 寫一題草稿，關掉再打開，草稿仍在
- [ ] 下載離線資料後開飛航模式，仍能開題與作答
- [ ] 備份中心能匯出 JSON

以上步驟依 Cloudflare 官方文件整理（[Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)）；本專案尚未實際部署到 Cloudflare 或在實體手機上驗收。
