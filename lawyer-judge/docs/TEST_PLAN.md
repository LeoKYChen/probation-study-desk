# 測試計畫與結果

## 執行方式

```bash
npm --prefix verification/sync ci   # 一次即可
node tests/run-all.cjs              # 完整測試
node tests/run-all.cjs --quick      # 只跑第一段
node tests/e2e/smoke.cjs [頁面...]  # 只跑冒煙測試
```

- **第一段（交付版本，含已匯入的 96 題）**：資料一致性、LawPlayer 試題轉換（樣本：使用者提供的兩份 .txt，加上 112、113 年憲法與行政法與 114 年勞動社會法三份曾切錯的試卷）、整合契約、離線清單、每日模擬與 AI 提示詞回歸、雙 AI 交接、書桌弱點、備份、函授、列印、共同科目（4 支）、書桌核心 26 項、冒煙測試、專業科目逐日檢查（週一到週日的科目與說明文字）。
- **第二段（暫存副本）**：在系統暫存目錄複製專案，先清空題庫跑一次冒煙測試（空狀態），再匯入 `tests/fixtures/sample-questions.json`（11 題，涵蓋每日排程的每一科）與 `sample-daily.json`，再轉換並合併匯入 `tests/fixtures/lawplayer/` 的真實試卷，跑瀏覽器端完整流程。交付版本的題庫不受影響。
- **冒煙測試**（`tests/e2e/smoke.cjs`）對 12 個主要頁面檢查：可載入、使用者可見文字不含觀護人專屬詞彙、沒有 NaN／undefined、320／360／375／390／414／430／600／768／1024／1280／1440 px 都沒有整頁水平溢出、沒有執行錯誤或缺檔、品牌標誌（含 CSS 產生的字）不是觀護人站的「觀」。

### 已知失敗：每日模擬端對端第 148 行（環境問題，非改版造成）

`verification/e2e-daily-v254.cjs` 第 148 行檢查匯出的 Markdown 檔名，在此環境的無頭 Chromium 中，下載檔名被回報為 `download`。**未修改的原觀護人專案在同一環境也在同一行失敗**，因此判定為環境差異。該測試前 147 行（作答、四格草稿、AI 提示詞、評語保存、切換題目等）都已通過。需要在 CI 或實機瀏覽器上確認。

### 未在此環境驗證

- WebKit（Safari 核心）：`unified-browser` 的 WebKit 版、`lectures/test-ui.cjs`、`mobile-rwd-seven-browser` 的 WebKit 部分。
- 實體手機、正式部署網址上的離線下載（`verification/offline-stage4-live-download.cjs` 需要部署後以 `STAGE` 指定網址執行）。
- 雙 AI 工作臺實際交接（外部網站；若部署網域不是 `leokychen.github.io`，需在工作臺端另行允許）。

### 題庫轉換的核對方式

39 份第二試試卷轉換後，以「每份試卷各題配分合計＝該科滿分」逐份核對（合卷：憲法與行政法 200、刑法與刑事訴訟法 200、民法與民事訴訟法每卷 150、商事法 100；國文與選試科目 100）。38 份相符；112 年憲法與行政法只有 100 分，經查 LawPlayer 下載檔與網頁都只收錄第 1 題，轉換程式會提出警告，未自行補題。此核對已內建在轉換程式中。

## 測試內容調整紀錄

依《網站基礎工程統一開發規範》9.2「不得為了讓 CI 變綠直接移除失敗測試」，每項調整都對應到新的契約：

| 測試 | 調整 | 理由 |
| --- | --- | --- |
| 寫死 426／553／125／127 題的斷言 | 改為依題庫檔實際題數或要求 ID 唯一 | 題庫由使用者匯入（D2） |
| 以心理學、犯罪學、少年事件處理法為測試科目 | 換成民法、刑法、民事訴訟法等，期望值依新評分準則重算（例如民法雷達 75%、刑法 6 項） | 科目更換（D3） |
| 7 科雷達圖、7 色 | 改為 10 科、10 色；圖表調色盤補 3 個對比度 ≥ 5.8:1 的顏色 | 原調色盤只有 7 色，第 8 科起會撞色 |
| 合卷題歸屬測試 | 改用「刑法與刑事訴訟法」合卷，並新增「民法題不得算入民事訴訟法弱點」 | D3 例外決策 |
| 週報、警察原題、Cloudflare、從舊版升級的測試 | 移除或移出該步驟 | 對應模組已刪除（D4） |
| `unified-integration` 的位元組出處帳本 | 改為檢查題庫三份副本一致、首頁六個入口、儲存鍵不變、不再引用已刪模組 | 原帳本只對原站有意義 |
| 離線資源數 ≥ 170／180 | 改為 ≥ 150，並以必要資源清單逐一檢查 | 刪除週報等資料後為 164 個 |
| 「新聞閱讀必須停用」 | 改為「新聞模組已移除」 | D4 |
