# 需求與驗收條件

## 用途與使用者

- **使用者**：準備律師、司法官考試的考生（產品負責人：LeoKYChen）。
- **核心問題**：把「讀過」變成「寫得出來」——選題 → 作答 → 核對 → 訂正 → 再次回想。
- **範圍**：沿用觀護人學習平臺全部功能，科目與題庫換成律師、司法官考試。
- **資料敏感度**：個人學習紀錄，只存在使用者瀏覽器；不處理個案或機密資料。
