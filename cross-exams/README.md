# 警察特考犯罪防治人員預防組｜指定四科（115年）

## 依使用者2026-10-22最新決定限定範圍

本次警察考試擴充**只收錄四科**：
1. 心理學 — 一般警察人員考試三等犯罪防治人員預防組。
2. 諮商與輔導 — 一般警察人員考試三等犯罪防治人員預防組。
3. 刑法與刑事訴訟法 — 一般警察人員考試三等犯罪防治人員預防組。
4. 犯罪學與犯罪預防 — 警察人員考試三等犯罪防治人員預防組（不同於一般警察）。

**排除**社會科學研究法、社會學與社會工作、犯罪分析、諮商輔導與婦幼保護，以及其他警察科目。既有非警察考試來源的426題與學習紀錄不受影響。
