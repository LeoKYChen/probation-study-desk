# 跨類科考古題：犯罪防治人員預防組（原題收錄規則）

## 收錄範圍：僅四科

考試類科必須依考選部原始名稱區分：

1. 一般警察人員考試三等「犯罪防治人員預防組」：**心理學**。
2. 同上：**諮商與輔導**。
3. 同上：**刑法與刑事訴訟法**。
4. 警察人員考試三等「犯罪防治人員預防組」：**犯罪學與犯罪預防**（與一般警察人員考試不同）。

不加入其他警察考試科目，包括社會科學研究法、社會學與社會工作、犯罪分析、諮商輔導與婦幼保護等。

既有觀護人及其他已收錄類科，不因本次指定四科而刪除。

## 重要的既定規格

- **只收錄考選部公布的歷屆原題**，逐字保存題目全文、子題與分數，不擅自改寫或把AI重新組織的題意當原題。
- 題目必須保留民國年、正式考試名稱、等別、類科、官方科目、題號、原卷網址以及文字與來源的核對狀態。
- 解析、考點整理與AI批改指引可另放欄位，不得覆寫原始題幹。沒有官方答案者不得冒稱官方標準答案。
- 保留複合官方考科名稱「刑法與刑事訴訟法」；可設定對應「刑法」或「刑事訴訟法」學習標籤，不把原題擅自分拆或改題。
- 共用試卷按官方試題識別避免重複，保持全部適用類科與原始出處。

## 目前實際進度

- PR #55已**移除先前錯誤添加的16道改編題及其備考書桌引用**。

- 115年四科及108至114年度的逐字原題，需完成來源核對後才能另行匯入。
- 既有426題及原作答紀錄未改動；不應把新增題源索引計入正式題庫總題數。
