# 跨類科歷屆試題｜第一階段題源索引（2026-10-22）

## 本階段範圍
- 核心目標是擴增**歷屆試題的來源**，不增加觀護人備考書桌的主要考科；不變更既有426題的ID、記錄和推薦規則。
- 納入：司法特考三等觀護人、心理測驗員、心理輔導員、監獄官；司法四等監所管理員；高普考心理相關類科；社會工作師；一般警察三等犯罪防治人員預防組；另列警察人員三等犯罪防治人員預防組。
- 官方資料以考選部考畢試題為準，原卷與題目輸入前分開標示驗證狀態，避免僅登錄URL即冒稱完成逐題匯入。

## 已處理事項
1. 建立 `cross-exams/index.html`，列出115年一般警察人員考試犯罪防治人員預防組五門專業考科的官方原卷連結。
2. 已實際查核考卷首頁之科目：刑法與刑事訴訟法、社會學與社會工作、諮商與輔導。其餘心理學、社會科學研究法目前只定位到考選部年度列表的原卷超連結，暫列待核對。
3. 分開「一般警察人員考試」與「警察人員考試」兩個不同來源，避免將後者的「犯罪學與犯罪預防」「犯罪分析」誤放到前者名下。
4. 題源頁不算入現有專業題庫，也不改寫學習紀錄。

## 後續逐題匯入門檻
每題需保留：
- `id`：穩定且不與現有題目衝突
- `year`：年度（民國年）
- `examName`、`examLevel`、`examType`：完整且不可混用的考試別／等別／類科
- `officialSubject`、`subject`：官方原考科與平臺主要考科（跨科只新增標籤而非更名）
- `questionNo`、`questionType`、`body`、`sourceUrl`
- `sourceKind`（官方原題／明確標記的改編或模擬）
- `verification`：來源／文字／題號／答案或僅練習要點核對
- 涉及共用試卷：以考試代號、科目代號、試題號碼去重，保留全部適用類科。

**驗收限制**：本階段只有官方試題「來源索引」，尚未完成跨類科歷屆題逐題蒐錄；不得將此頁描述為所有類科題目已匯入、可在站內作答。來源核對後才逐年、逐科匯入，申論沒有官方標準答案時不得捏造。
