# 觀護人練習臺 v2.5

以司法特考三等觀護人準備為主的考古題與案例練習網站。可選科目開始作答，查看參考評分、逐點核對答案，並整理後續補強項目。

## 本版功能

- **科目入口首頁**：按科目進入考古題，或每日模擬題；一鍵開始今天的少年事件處理法考古題。
- **310 題自動參考分數**：對待校準題提供自動參考評分；辨識線索不代表內容一定正確。
- **逐點核對與誤判回饋**：核對得分要點，可記錄漏辨識、內容誤判、合理異說及需要補強之處。
- **補強清單**：彙整需核對與待補強項目，完成後可標記已補強並回到原題練習。
- **每日模擬題按科目顯示**：依科目選取已收錄案例、參考答題架構與理論應用表格。
- **紀錄備份**：考古題與每日模擬題各有匯出／匯入入口。

## 使用方式

1. 在首頁選科目，按「練一題」，或按「開始今日考古題」。
2. 先自行作答，再使用內建判定與答案核對功能。
3. 逐點查看辨識結果，必要時保存誤判回饋。
4. 回到首頁開啟補強清單，安排再次練習。
5. 定期匯出紀錄；換裝置或瀏覽器時再匯入。

「今天的考古題」從現有題庫選出，優先選尚未完成的題目；不是每日新增題目。「每日模擬題」也使用現有題庫，更新 questions.json 才會增加內容。

## 題庫與資料

本包考古題共有 426 題（主題庫 374 題、相關題庫 52 題）。其中 310 題屬自動參考評分待人工校準範圍，並非全站只有 310 題。每日模擬題另收錄 30 題，以題庫檔案的更新日期為準。

題幹、考試年度及出處依各題資料顯示；部分轉錄、解析、分類與參考架構仍待人工覆核。原始試題及引用資料的權利與使用條件應依各來源確認；程式碼授權不代表第三方資料一併授權。

## 評分限制

自動分數僅供練習參考，並非官方閱卷分數。关键词或文字線索命中，不能取代對法律時點、事實涵攝、理論應用及合理異說的實質判斷。誤判回饋會保存於本機，尚不會自動修改分數或全站評分規則。

法律題應核對現行法；本版不提供即時法規更新保證，也未串接外部大型語言模型作為即時閱卷服務。

## 紀錄保存

紀錄保存在目前網站網址所屬的瀏覽器儲存空間；不會自動跨裝置同步。測試站與 GitHub Pages 站的紀錄各自保存；從測試站移轉請先匯出再匯入。考古題、每日模擬題紀錄分開保存，備份入口請各自使用。

## 部署

本版為靜態 HTML／JavaScript 網站，可部署至 GitHub Pages，無須安裝 Node.js 或建立付費後端。

發布目錄應包含以下檔案：

| v2.5/ | 考古題作答、評分與補強功能 |

詳細步驟見本包「UPLOAD.md」。
