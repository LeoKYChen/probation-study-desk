# 觀護人練習臺｜晚間學習室

以臺灣司法特考三等觀護人備考為主的自主學習網站，整合考古題練習、參考評分、逐點核對、補強清單，以及晚間摘要閱讀與每日申論模擬題。

網站採靜態 HTML、CSS 與 JavaScript，部署於 GitHub Pages。學習者可以直接使用網站；維護者可透過 Google Apps Script，將指定 Google Drive 資料夾中的題目與閱讀文件更新到網站。

**目前介面版本：v2.5。文件更新日期：2026-10-09。**

| [晚間學習室](https://leokychen.github.io/probation-study-desk/daily-simulation/) | 晚間摘要、新聞整理與每日模擬題 |

## 專案目標

把閱讀資料、考點理解、申論作答與後續複習串在一起，協助使用者形成持續練習的習慣：

1. 閱讀司法、法制、少年司法與公共事務資料。
2. 依科目與考點選擇考古題或模擬題。
3. 先自行列爭點、寫答案，再查看參考架構。
4. 核對辨識結果與待補強項目，安排再次練習。
5. 定期匯出作答紀錄，保留學習成果。

## 主要功能

### 考古題練習臺

- 依科目、年度與題源類科選擇已收錄題目。
- 作答與草稿保存於目前瀏覽器。
- 提供內建參考判定與答案核對功能。
- 對310題待校準題提供自動參考評分；310題是功能適用範圍，不是全站題目總數。
- 支援逐點核對、誤判回饋與補強清單。
- 提供考點整理、理論診斷與相關練習入口，實際內容依各科已建立資料而定。
- 支援作答紀錄匯出、匯入及清除。

### 晚間摘要與新聞閱讀

- 收錄來源文件中的司法與法制、少年司法與 CRC、AI／程式開發、公共事務及備考資料。
- 站內閱讀文件全文，保留來源中的引用與連結。
- 支援全文搜尋、日期篩選、主題篩選與新舊排序。
- 支援閱讀收藏、已讀標記與未讀資料篩選。
- 可查看新聞資料最後同步時間；部分同步失敗時保留可用的既有內容。

主題與日期部分依文件標題、內容關鍵字及來源修改時間推定。分類標籤不等於內容已經完成專業查核。

### 每日申論模擬題

- 依犯罪學、心理學、諮商與輔導、少年事件處理法、保安處分執行法、刑事訴訟法及跨科整合等科目切換。
- 搜尋案例、考點、理論與參考內容。
- 作答自動保存，支援題目收藏與待複習標記。
- 參考答題架構、核心爭點與四欄理論應用表預設收合，方便先作答再對照。
- 支援匯入 v2.5 備份中的每日模擬題紀錄，並匯出每日模擬題作答。
- 清除全部每日練習紀錄前會要求確認，並嘗試下載一份備份。

**每日模擬題不提供自動評分。** 考古題練習臺的參考評分是另一項功能。

## 使用方式

### 練習考古題

1. 在首頁選擇科目，進入考古題練習。
2. 先自行作答，再按內建判定按鈕。
3. 逐點查看參考結果，對照題目事實、理論或法源。
4. 保存誤判回饋與補強項目。
5. 回到補強清單，安排重寫與複習。

### 閱讀晚間摘要

1. 開啟晚間學習室，選擇「晚間摘要／新聞」或「全部閱讀資料」。
2. 使用日期、主題或全文搜尋找資料。
3. 點「開始閱讀」，查看完整文件與引用來源。
4. 收藏值得再讀的文件，或標記已讀。

### 練習每日模擬題

1. 在晚間學習室左側選「每日模擬題」。
2. 選科目與題目，寫下自己的答案。
3. 作答後展開參考架構、爭點與理論應用表。
4. 將需要再練的題目加入待複習。
5. 定期匯出紀錄；換裝置或瀏覽器時再匯入。

## 作答保存與備份

個人作答、回饋、收藏與已讀等資料保存在目前瀏覽器的本機儲存空間，不會因瀏覽公開網站而自動上傳至本儲存庫或維護者的 Google Drive。

- 不同裝置、瀏覽器或網站來源不會自動共享本機紀錄。
- 清除網站資料、使用無痕模式或瀏覽器儲存失敗，可能影響紀錄保存。
- 更新前、換裝置前與清除紀錄前，請先使用匯出功能。
- JSON 作答備份可能包含個人文字，請自行妥善保存，不要上傳公開儲存庫。
- 私人測試站與正式 GitHub Pages 使用不同網站來源；移轉作答需要手動匯出、匯入。

| 功能入口 | 備份行為 |
| --- | --- |
| 考古題練習臺 v2.5 | 可匯出／匯入該入口支援的作答備份；目前完整備份格式可包含考古題與每日題紀錄 |
| 晚間學習室・每日模擬題 | 匯出每日模擬題作答；可從 v2.5 完整備份中取出每日題紀錄匯入 |
| 閱讀收藏、已讀與題目收藏 | 保存在目前瀏覽器，不包含在每日題作答備份內 |

晚間學習室匯入完整備份時，只處理每日模擬題紀錄，不套用考古題紀錄。同題以匯入備份的作答為主；未出現在備份中的原紀錄保留。題目尚未收錄的紀錄仍可保留於後續匯出檔。

## 自行部署與維護

### 使用自己的 GitHub Pages

1. Fork 或下載本專案，建立自己的儲存庫。
2. 保留首頁、`v2.5/`、`daily-simulation/` 及所有被引用的資源。
3. 在儲存庫設定中啟用 GitHub Pages，選擇適合自己專案的發布來源。
4. 修改程式中的原站絕對網址、維護者資訊與必要路徑，再驗證首頁、作答及閱讀功能。
5. 等待 Pages 發布成功，測試手機與電腦操作。

本專案包含已發布的JSON，複製後可以先使用該份資料；持續更新需要另外設定自己的來源與同步工具。既有同步模組有儲存庫與網站網址限制，不能只修改 Token 就直接寫入另一個儲存庫。

### 更新現有網站

1. 先匯出個人作答，保存更新前程式及 commit。
2. 依功能範圍更新檔案，保留既有題庫路徑與題目ID。
3. 更新介面時，不要用安裝包的空白 `documents.json` 覆蓋已同步新聞。
4. 不要刪掉或覆寫最新 `questions.json`。
5. 等發布成功後，核對題目、作答、備份與資料更新時間。

移除舊版本或測試資料夾前，請先檢查實際引用與保留備份；資料夾名稱本身不能證明它已不再使用。

## Google Apps Script 新聞同步設定

新增新聞模組不需要重寫原每日題庫程式，也不應替換原 `syncDailyResources`。

在自己的 Apps Script 專案新增 `ReadingNewsSync.gs`，並於「指令碼屬性」設定：

| 屬性 | 用途 |
| --- | --- |
| `GITHUB_REPO` | 目標儲存庫；目前維護模組使用 `LeoKYChen/probation-study-desk` |
| `GITHUB_BRANCH` | 寫入分支，例如 `main` |
| `GITHUB_TOKEN` | 可寫入目標儲存庫內容的 Token |
| `NEWS_SOURCE_FOLDER_ID` | 已確認可公開全文的 Drive 資料夾ID |
| `NEWS_PUBLICATION_ENABLED` | 確認公開來源後設為 `true`，否則禁止新聞同步 |
| `NEWS_INCLUDE_SUBFOLDERS` | `true` 讀取子資料夾；`false` 只讀本層 |

原題庫同步所需的 `SOURCE_FOLDER_ID`、`MD_SOURCE_FOLDER_ID` 等設定應依原程式保留；新聞模組使用獨立的來源屬性。

設定順序：

1. 核對來源資料夾的每份內容都能公開。
2. 在自己的 Google 帳號完成所需授權。
3. 執行 `previewReadingNews`，確認來源數量與讀取結果；此步不寫入GitHub。
4. 執行 `syncReadingNews`，確認寫入與讀回核對成功。
5. 等 GitHub Pages 發布後，到網站核對全文與來源。
6. 在 `Asia/Taipei` 時區建立時間驅動觸發條件，安排在摘要來源產出後執行。
7. 定期查看執行紀錄、Token期限及同步狀態。

Apps Script 以觸發條件建立者的帳號權限執行；不需要電腦持續開機，但受 Google 的服務配額與執行限制影響。時間觸發條件可能在選定時段內調整，不保證精準某一分鐘。參考 [Google 可安裝觸發條件文件](https://developers.google.com/apps-script/guides/triggers/installable)。

網站顯示一次成功同步，不代表每日觸發條件一定已啟用或每次都會成功；仍需由維護者檢查自己的排程。

### 新聞同步行為與限制

- 支援 Markdown、TXT 與 Google 文件。
- Google 文件讀取內文、文件分頁與子分頁、標題、清單、超連結及文字表格；不搬移圖片、附件、註解、頁首頁尾或原始版面設計。
- 同一來源檔案使用穩定雜湊ID；修改同一檔案會更新既有項目。
- 刪除來源後重建另一個檔案會取得新ID，可能形成另一份文件。
- 讀取失敗時保留已發布版本；全部來源失敗時停止寫入。
- 使用目前檔案SHA進行條件寫入，衝突時停止，不強制覆蓋；參考 [GitHub Contents API](https://docs.github.com/en/rest/repos/contents)。
- 內容相同時不產生新提交，網頁時間維持上次資料寫入時間。
- 目前模組限制300份支援文件、每份250000字元與總JSON約4MB；大量資料需另行規劃。
- **來源移出或刪除不會自動移除已發布內容。** 如需下架，先停用同步、移出來源並刪除公開JSON的對應項目；舊Git提交仍可能保留之前內容。

若使用獨立的公開來源資料夾，新的摘要也必須放入該資料夾。只更新另一個私人資料夾，不會自動更新公開網站。

## 公開內容與個人資料

本儲存庫與正式網站公開可讀。被寫入 `documents.json` 的全文會成為公開內容，不因 Google Drive 原始資料夾仍為私人而保密。

- 公開來源資料夾的全文與後續新增文件均需由維護者確認公開範圍。
- 不應把私人筆記、真實案件個資、個人作答、密碼或Token放入公開來源或儲存庫。
- 原始Drive文件 ID使用雜湊代碼，文件連結指向本站；這不會遮蔽來源全文中自行寫入的個資。
- 新聞模組會略過含Drive／Docs連結或常見憑證格式的來源，但這不是完整的個資或機密辨識系統。
- Token只設定於受信任的Apps Script 專案；有專案編輯權限的人可能透過程式存取指令碼屬性，請審慎授予編輯權限。

## 評分與內容限制

本專案是學習輔助工具，不是考選部、司法機關或補習班的官方閱卷系統。

- 自動參考分數不是官方分數，也不是經獨立專業閱卷校準的保證。
- 文字與關鍵詞命中，不代表法律見解、理論說明、個案涵攝或結論必然正確。
- 部分內容可能因來源、時點、轉錄、分類或合理異說而需要人工覆核。
- 誤判回饋與補強紀錄供使用者整理學習；不會自動修改全站評分規則。
- 法律題應依題目要求核對法律時點與現行法；網站不保證全部法規與函示即時更新。
- 題目出處及改編標示依來源資料呈現；來源有標示不等於已核對官方原卷。
- 新聞與閱讀文件依來源收錄，不代表維護者已查核全文中的所有主張。

使用者應對照考選部原始試題、現行法規與可靠原始資料，並自行判斷如何使用參考內容。

## 常見問題

| 問題 | 說明 |
| --- | --- |
| 網頁按「更新題庫」後沒有新題 | 按鈕只重新讀取JSON；需要來源有新內容，且原題庫同步完成 |
| 新聞最後同步時間沒有改 | 來源可能未變、同步未執行或執行失敗；內容相同時不寫入新時間 |
| 原答案在另一台裝置不見 | 作答保存在原裝置的瀏覽器；請匯出再匯入 |
| 閱讀收藏不在作答備份裡 | 收藏、已讀與作答使用不同紀錄；目前每日題備份不含收藏與已讀 |
| 每日模擬題沒有自動分數 | 此區使用參考架構與自行核對；自動參考評分在考古題練習臺 |
| 某份閱讀文件仍是舊版 | 來源讀取可能失敗，程式會保留前次內容；查看維護者執行紀錄 |
| 從Drive刪掉文件但網站仍有 | 新聞模組不自動下架已發布文件，需按維護流程移除公開項目 |
| Fork後沒有自動更新 | 需要自己的來源資料夾、Apps Script、授權、Token與觸發條件 |
| 修改後仍看到舊頁 | 先確認Pages發布成功，再重新整理；不要為此清除所有學習資料 |
