# 觀護人練習臺

收錄 108–115 年考古題，提供爭點整理、系統初評、
考科重點地圖，以及刷題王、阿摩參考連結。

## 網站入口

- [正式站](https://leokychen.github.io/probation-study-desk/)
- [固定測試站](https://leokychen.github.io/probation-study-desk/preview/)
- [每日模擬題](https://leokychen.github.io/probation-study-desk/daily-simulation/)

## 資料夾用途

| 位置 | 用途 |
|---|---|
| 根目錄 index.html | 正式站入口，目前載入 v2.4 的資源 |
| v2.4/ | 正式站使用的程式與題庫，請保留 |
| preview/ | 固定測試站，新功能優先在此測試 |
| daily-simulation/ | 每日模擬題及自動同步題庫 |
| v2/ | 舊版網站，暫時保留 |
| daily-simulation-md-test/ | Markdown 模擬題測試頁與題庫，暫時保留 |
| daily-simulation-md-test-20261005/ | 另存的測試題庫，內容不同，待確認後整理 |

## 更新原則

1. 新功能先更新 preview，測試完成後再更新正式站。
2. 每日模擬題維持 daily-simulation 的路徑。
3. 搬移或刪除檔案前，先確認網站引用路徑並保存備份。
4. 作答紀錄保存在使用者的瀏覽器，請定期使用網站的匯出備份功能。
