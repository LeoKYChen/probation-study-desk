### 權利證據欄位（後續逐題填寫）

| 欄位 | 最低要求 |
|---|---|
| 題目身分 | 題號、年份、場次、正式／參考／試辦／改編狀態及原始卷次證據 |
| 來源固定 | 原始網址、repo、檔案路徑、commit SHA／檔案雜湊 |
| 元件拆分 | 試題原文、篇章、圖片音訊、選項、官方答案、作者自編解析／中譯分別記錄 |
| 利用依據 | 官方公開授權、權利人許可、具體適用法律依據或其他可核對證據，含使用條件 |
| 使用範圍 | 個人學習、課堂分享、第三方公開網站、有無非商業／衍生／署名限制 |
| 審查結果 | 暫緩／可供內部比對／待複核／核准發布；審查人、日期及證據連結 |

任何元件欠缺確認即不放行該元件；不能將「有正式試卷來源」當成圖片或自編解析的授權。

## 4. 單題驗收作業程序

1. 先以原始考卷或可信一手來源確認試題性質及題號，再對照作者整理版本和本地標準化版本。
2. 分別檢查題幹、選項、答案、解題論證、文章及必要圖像；保留來源衝突與尚待查證標記，**不得自行「修正」來源又隱瞞差異**。
3. 整理原作者解析、翻譯、註解與官方試題的權利差異；可用於內部核對不等於允許重新公開傳播。
4. 每筆留下來源證據、具體結果、修正理由、人工覆核紀錄。題組須在篇章及所有必要子題一起通過後才算完整。
5. 只有內容核對、權利依據及 UI 顯示均核准，才得從審查候選清單移至可發布清單；現階段不實作自動發布。
